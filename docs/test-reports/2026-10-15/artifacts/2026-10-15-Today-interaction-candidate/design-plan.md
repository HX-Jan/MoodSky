# Today 记录交互候选设计计划

范围：第一周 YF02—YF04 可操作表单与 H02 接口消费者候选。保留实际项目、云端资源和数据库；候选在隔离副本验证，正式应用须拥有者审查。

配色沿用现有变量：背景 #F5F7FC、表面 #FFFFFF、正文 #22314D、说明 #68758C、主操作 #385BC7，字段错误 #A33A42。只增加页面局部规则，不改全局设计变量。

字体：系统中文 PingFang SC / Microsoft YaHei；标题 44rpx、字段标题 30rpx、正文 28rpx、辅助文字 24rpx。左对齐，日期与记录状态在同一行，避免额外装饰标签。

布局：天气选择是主视觉，一排五个可点击的天气格，选中状态同时用边框与勾选文字标识。其下在同一连续表单放标签、可空正文、计数及保存操作。错误和结果紧邻操作，删除和放弃草稿采用页内确认。

```
日期 / 更改日期                   尚未记录
今天的天气，由你定义
[五种天气，可选一项]
固定标签                           已选 0/5
[八个标签，可选多项]
写一点，也可以留白                0/1000
[正文输入]
[保存记录]      [删除，仅已有记录]
[真实结果 / 原操作重试 / 重新读取]
```

复核：沿用现有蓝色，但取消重复占位卡片与大写装饰抬头；用五种天气本身组织页面。没有营销数字、装饰渐变、自动动画或新增字体依赖。原生按钮保留可见文字与禁用状态，限长按共享 Unicode 码点工具；原生 textarea 不用 UTF-16 maxlength 截断 emoji。

数据边界：正常分支继续调用现有私人 service，不绕过门禁。仅当隔离配置 journalDemo:true 且 cloudEnabled:false 时，显式选择内存演示适配器。演示不写文件、Storage、云函数或数据库，也不是生产事务、授权或幂等验收。
