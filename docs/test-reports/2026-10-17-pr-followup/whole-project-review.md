## 三项可复现修正

1. **响应矛盾仍可能显示成功**：原小程序接口接受 `ok:true + data + error` 或 `data:undefined`。现要求成功有有效 data 且不含 error；失败只含 error，不能夹带 data。后台采用同一互斥规则。无法确认时返回 INVALID_RESPONSE，原有控制器继续保留输入和原请求。
2. **合成停用/注销状态在重开后恢复 active**：状态原只存当前对象内存。现将状态放入同一合成账号的缓存作用域，重开、切换后仍保持 disabled/closed，只有“重置演示”恢复 active；两个账号保持隔离。不是微信账号或正式服务端状态。
3. **Me 的迟到健康检查覆盖页面**：现以页面序号、处置标记和账号缓存代次核对结果；离开页面、切换/重置账号或发起更新检查后，旧结果不再写回。该检查继续使用本地合成响应。
