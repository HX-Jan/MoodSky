# Jia7Zhu 提交界面的比对与本地对齐

## 来源和原因

设计来源为 [PR #12](https://github.com/HX-Jan/MoodSky/pull/12)，提交 a01e5b64d5469251738fe80da084f88c3e7c7204，合并提交 da95d4a。该 PR 只增加 docs/design/w1 下的原型、规范与研究材料，未替换 miniprogram 页面和 tokens。因此设计虽已合入，运行界面仍是其他成员的旧实现；后续校园 PR 也沿用了旧页面样式。这是整合时未落实视觉设计的差异。

当前本地分支从已整合成员成果的 main 0bfdb01 开始，依据拥有者本次“按照他提交的界面”的要求实现。早先暂停的字体草稿和 UI PR #18 未覆盖本分支。

## 功能与验证边界

- 原稿中真实地点、身份和静态记录不当作当前真实数据；页面日期与月历仍由实际业务日期/当前演示记录计算。
- 实际保存仍只有 SUNNY、PARTLY_CLOUDY、CLOUDY、RAINY、STORMY；原稿的暴雨、台风、自定义只是禁用入口，不能发送到保存接口。
- 私人记录的版本竞争、重试、日期边界、正文隐藏、账号隔离和真实服务未接入状态保留；没有改云函数、共享契约或数据库。
- 减弱动效、写作提示等原型设想没有借本次样式迁移虚构成已实现功能。
- 检查在本机离线配置下执行，不部署、不调用云端、不清理保留数据、不更新 GitHub。

本轮实际检查和模拟器证据见下文。字体使用原规范允许的系统中文无衬线回退，未分发外部字体；真机、放大字体与不同字体回退仍需另测。日期、可用能力和真实数据边界导致的差异已列明，不声称逐像素一致或完成原型中的全部业务。

## 本轮实际结果

完整 lint、format、结构与 272 项测试通过，包含未开放天气不能改变/保存记录、周一起始月历日期、导航成功后选中状态，以及历史入口的游客隔离回归。模拟器逐项 25 项通过，见 [记录](native-checks.json)；截图：[今天](today.jpg)、[校园](campus.jpg)、[天气宇宙](universe.jpg)、[我的](me.jpg)、[私人记录](record.jpg)。

模拟器检查中遇到一个旧的本地合成导出任务，已核实只是展开已有任务；测试改为比对展开前后的任务 ID，未清理旧状态，也未创建导出。自动化连接曾混用旧页状态，重新打开本轮项目窗口后逐页确认并截图，未把编译中或旧页截图作为最终证据。随后针对天气显示名称和开关色值作了显示层一致性修正，272 项完整检查再次通过；交互和云端边界未变。

当前分支只在本地保存，尚未上传 GitHub，也没有部署/上传微信体验版。原始字体草稿保留在原工作副本，不混入本轮。

最后补充只读核对：禁用保存按钮的实际背景为 rgb(217, 225, 218)，与原稿 border 色值 #D9E1DA 一致；私人记录页已使用多云 / 小雨 / 风雨的原稿显示名，实际保存编码未改变。
