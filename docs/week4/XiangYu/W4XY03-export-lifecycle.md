# W4XY03 导出绑定与时间失效验证记录

## 1. 架构实现核对

- **存储机制**：不使用公开临时云存储链接，导出内容直接存于受限 `export_jobs` 的 `content` 中。
- **全局限制**：导出按来源集合或数据项检查 2000 条限制，文件受 512 KiB 独立限制。
- **时间失效**：文件就绪（ready）后，**24 小时**后过期失效。

## 2. 导出失效行为（分开说明）

- **状态查询**：账号 `epoch` 或来源版本（revisions）变化后，查询导出状态时会返回 `expired`。
- **文件下载**：下载已失效的文件时，系统会返回 `CONFLICT` 拒绝请求。
