# W4XY03 导出绑定与时间失效验证记录

## 1. 架构实现核对

- **存储机制**：不使用公开临时云存储链接，导出内容直接存于受限 `export_jobs` 的 `content` 中。
- **文件大小限制**：文件体积受 **512 KiB**（`MAX_BYTES=512*1024`）独立限制。
- **记录上限说明**：2000 条限制（`MAX_RECORDS=2000`）是按来源集合或格式化数据项检查，并非「单次整体最多 2000 条」。

## 2. 版本失效机制

- **触发条件**：当账号的 `epoch` 或来源 `revisions` 发生变化时，均会触发系统拒绝（抛出 `CONFLICT`），导致旧导出失效。

- 本项保持**待验证**，不填写已通过。
