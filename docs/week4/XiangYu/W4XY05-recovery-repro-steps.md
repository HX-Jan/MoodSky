# W4XY05 恢复演练复现材料

## 复现目标

证明“数据库回滚后，已注销用户的删除账本（deletion_markers）能重放，防止已删数据复活”。

## 复现步骤

1. 在本地合成环境中，准备账号 A，并生成 3 条 `journals` 记录（j1, j2, j3）。
2. 执行账号 A 的注销流程。
3. 此时 `deletion_markers` 中有 3 条记录。
4. **模拟灾难恢复**：使用本地测试脚本，将主库恢复到注销前的状态（j1, j2, j3 全在），账本也恢复到旧状态。
5. **执行重放脚本**：从账本拉取已完成的删除标记，强制从主库删除对应记录。

## 验证结果

- 执行重放后，主库中 j1, j2, j3 被彻底清除。
- 账号 A 仍为 `disabled`。
- 结论：防复活机制有效。
