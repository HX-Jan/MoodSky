# W4XY01 数据库配置交接报告

## 1. 基础配置与溯源

- **环境名称**：mood-sky
- **账号映射机制**：采用内部 `ownerId`，通过微信 `_openid` 唯一映射。客户端不直接暴露微信身份。
- **客户端权限（真实生效状态）**：禁读禁写（`read: false, write: false`），所有访问经过云函数受信路径。
- **唯一索引配置**：`accounts` 的 `_openid` 唯一，`journals` 的 `ownerId + date` 唯一。已在测试环境验证过 `E11000` 冲突。
