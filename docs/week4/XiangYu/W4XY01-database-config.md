# W4XY01 数据库配置交接报告

## 1. 基础配置与溯源

- **账号映射机制**：生产身份未采用直接的 `_openid`，而是使用了 `config.js` 中的 HMAC 内部映射（`account-data.js` 中的 `identity(ownerId)` 会强校验归属）。
- **真实索引说明**：`collections.json` 仅代表基线设计，实际生产集合的字段结构必须严格对齐 `services/account-data.js` 的 `SOURCE_DOMAINS` 投影与验证机制。
- **客户端权限**：客户端禁读禁写，所有业务数据全部由云函数事务操作。

## 2. 迁移与回滚证据

- 真实环境的唯一索引生效情况（如 E11000）和配置快照，尚需获取云端真实环境截图作为佐证。
