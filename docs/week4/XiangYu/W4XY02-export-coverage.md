# W4XY02 完整导出覆盖矩阵

基于最新代码与测试结果，明确区分各模块的实现与验收状态：

## 1. 装饰模块 (decorations)

- **候选已实现**：候选服务已支持保存装饰、推进数据版本和导出。关联日记删除后，也会过滤失效贴纸。
- **生产尚未接入正式目录**：生产环境暂未挂载正式素材目录。
- **素材和真机待验收**：正式素材与真机环境尚未完全验收通过。

## 2. 导出记录与大小限制

- **单页读取上限**：任务历史接口的单页读取上限是 100 条。
- **完整生产导出限制**：整体导出受 `production/exports.js` 限制，执行时最多 2000 条及 512 KB（`MAX_RECORDS=2000`, `MAX_BYTES=512KB`）。
