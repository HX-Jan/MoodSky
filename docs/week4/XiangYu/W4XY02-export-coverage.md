# W4XY02 完整导出覆盖矩阵

## 1. 接口限制与导出上限

- **单页限制**：历史分页查询接口（如任务历史）的单页读取上限是 100 条。
- **生产导出上限**：完整生产导出按来源集合或格式化数据项检查，最多 2000 条（`MAX_RECORDS=2000`）；导出的文件体积另受 512 KiB（`MAX_BYTES=512*1024`）独立限制。

## 2. 逐模块字段覆盖表

| 模块                   | 导出字段与范围核对                                                  |
| ---------------------- | ------------------------------------------------------------------- |
| 天气日记 (journals)    | 日期、天气、标签、正文及自定义天气名称 (weatherName)                |
| 收藏 (favorites)       | 地点 ID、地点名称（按来源记录）、收藏时间                           |
| 任务历史 (tasks)       | 任务 ID、状态、日期                                                 |
| 偏好资料 (preferences) | 卡片预览设置、装饰开关及 profile 字段                               |
| 装饰 (decorations)     | 月份、贴纸与背景（受失效贴纸过滤机制影响）                          |
| 打卡 (check-ins)       | **地点 ID**、**日期**、**完成时间**（地点名称与自报标记按来源注明） |
