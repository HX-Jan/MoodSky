# W4XY02 完整导出覆盖矩阵

## 1. 装饰模块 (decorations)

- **候选已实现**：候选服务已支持保存装饰、推进数据版本和导出。关联日记删除后，也会过滤失效贴纸。
- **生产尚未接入正式目录**：生产环境暂未挂载正式素材目录。
- **素材和真机待验收**：正式素材与真机环境尚未完全验收通过。

## 2. 导出记录与大小限制

- **单页读取限制**：任务历史接口的单页读取上限是 100 条。
- **生产导出上限**：完整生产导出的 2000 条（`MAX_RECORDS=2000`）限制是按来源集合或格式化后的数据项检查；导出的文件大小另受 512 KiB（`MAX_BYTES=512*1024`）独立限制。

## 3. 逐模块字段覆盖表（基于导出准备器、格式化器与生产入口）

| 模块                   | 导出字段与范围核对                                            |
| ---------------------- | ------------------------------------------------------------- |
| 天气日记 (journals)    | 包含日期、天气、标签、正文及 **自定义天气名称 (weatherName)** |
| 收藏 (favorites)       | 包含地点 ID、地点名称、收藏时间                               |
| 任务历史 (tasks)       | 包含任务 ID、状态、日期（受单页 100 条读取限制约束）          |
| 偏好资料 (preferences) | 包含卡片预览设置、装饰开关及 **profile** 字段                 |
| 装饰 (decorations)     | 包含月份、贴纸与背景（受失效贴纸过滤机制影响）                |
| 打卡数据 (check-ins)   | 包含用户打卡记录（依据生产入口实际提取）                      |

_注：以上字段均基于当前导出准备器、格式化器和生产入口核对。_
