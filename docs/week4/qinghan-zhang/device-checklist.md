# 地点推荐与到达后手动打卡设备清单

设备：Xiaomi 14 Ultra；HyperOS 3.0.308.0；微信 8.0.80（用户提供，实际测试前复核）。源码 SHA、包标识、环境、执行日期、操作者待填。以下均未执行，不提前填通过。

1. 首次登录进入校园：列表能结束加载，空数据与读取失败有区别，失败可重试。
2. 阅读推荐地点、推荐理由、文字方位、开放与进入限制；过期或停用地点不能作为有效推荐。
3. 游客可浏览；需私人写入时登录，登录返回不丢失合理的页面上下文。
4. 到达后手动点击打卡：明确为用户自报，服务器确认前不显示完成。不申请位置权限，不打开地图。
5. 快速重复点击、断网、超时和恢复后重试：保留原 requestId 与 payload，无重复完成；未知结果不能当成功。
6. 重开读取本人状态和历史；同日重复与跨日行为依最终契约核对，不自行推测规则。
7. 页面可见期间切 A/B 账号：立即清空旧私人状态并读取新状态，迟到响应不回填。
8. 页面隐藏期间切号：隐藏时不发起新读取，重新显示后读取当前账号，旧响应无效。
9. 字体放大、长名称、长方位文字和失败提示可阅读、按钮可点击。

每项填预期、实际、通过/失败/未测和证据路径。基本打卡未接通时对应项填未测及接口缺口，不能用本地收藏测试代替。Android 当前一台；iOS 与指定其他设备未覆盖。定位、坐标和地图不是本周验收前置；照片上传后续安排。
