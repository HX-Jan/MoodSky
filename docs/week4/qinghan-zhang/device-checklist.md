# QH05 设备补测与联调步骤

执行前记录源码/候选包标识、云目标、设备型号、系统、微信版本、日期、操作者；未填写时状态为未测。复核人 Yuen Lin，#23 保持开放。

1. 首次打开校园页：不得自动请求定位；列表、筛选、详情可用。
2. 主动点击定位并同意隐私/位置授权：记录真实弹窗及结果，不记录精确坐标。
3. 拒绝授权：显示降级提示，继续筛选、翻页和打开详情。
4. 在系统/微信设置撤回权限后返回，再主动请求：记录弹窗或平台拒绝，确认浏览仍可用。
5. 隐藏页面后才返回定位结果：旧响应不得覆盖新页面。
6. 未核验或坐标系未知地点：不得调用地图。此项不能替代实际地图失败验证。
7. 在负责人提供可靠坐标且已核验的候选资料后，打开地图；通过开发者工具故障注入验证 fail 回调，再在指定手机验证返回路径。
8. 分别登记 Android、iOS、指定华为；没有设备不填通过。线上入口未开放时由负责人提供固定候选包，不能将无弹窗认定成功。
