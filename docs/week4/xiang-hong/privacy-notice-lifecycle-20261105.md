# 隐私指引的页面与旧回调保护（11月5日）

登录和“我的”原先会在隐藏、卸载或静态分享预览状态仍执行隐私入口，先前的失败回调也可能在离开再返回后弹提示。连续打开时，旧失败与重复失败可能干扰当前页面。这是实际Page在本机替身中复现的交互问题，没有认定真实设备已发生隐私事件。

入口现按页面状态忽略隐藏、卸载、静态预览和分享重定向页面；每次阅读保留独立的内存提示标记，后一次取代前一次，隐藏/卸载时清除。旧回调即使在返回后到达也不提示，同一次失败最多提示一次。正常可见页面的缺少接口、同步异常和异步失败仍保留原中文恢复提示，可再次打开。

仅约束应用自身的提示，不取消已打开的微信原生隐私界面，也不假设原生界面的打开/关闭回调时序。没有设置同意、登录、收集或上传状态，不把查看指引视为接受授权。隐私入口与必要提示继续保留，模板、样式和文字未改。

新增6项实际Page回归在基线全部失败，覆盖两个页面的隐藏/卸载/静态入口、离开再返回的旧失败、较新阅读取代旧失败以及同次失败重复通知；旧缺接口/异常恢复4项保持。隐私初修相关45项通过；追加设置保护后的相关48项、cloud:prepare/check完整1396项、34份维护文档/546本地链接及格式/结构/类型检查通过。VM只补充标准定时器全局以执行真实卸载路径，不替换业务分支。

同时补“我的”账号/任务不可用入口和检查更新：隐藏、卸载、静态预览或分享重定向状态不再弹出旧页面的服务提示或触发更新状态框，返回后仍可操作。3项新增实际Page回归在基线全失败；不改变可用页面的功能门禁、更新处理及中文提示。

本次无视觉变化，不重复原生模板/样式编译或旧工具失败流程；Page合成结果不等于真实手机、原生指引内容/后台生效或平台授权已验收。无新SDK、网络目的地、持久字段、权限、云部署、微信上传及真实用户数据操作；原隐私/UGC、内容审核和独立签认待办保留。
