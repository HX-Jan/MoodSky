# 打卡历史按实际时间排序（11月5日）

触发：历史兼容读取接受无小数及1—3位小数的UTC时间。旧的字符串排序会把`01:00:00Z`排在`01:00:00.900Z`前面；同一时刻的`.1Z`和`.100Z`也可能打乱地点标识的稳定顺序。客户端沿用字符串校验时，正确的跨页数据会误报“记录已更新”，逆序数据反而可能通过。
