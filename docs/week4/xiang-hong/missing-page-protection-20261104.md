# 异常链接与待确认操作保护

从main `fa6363dae35d77b71c571542b1f0f30c48a14254`继续维护。校园基本手动打卡已由[PR128](https://github.com/HX-Jan/MoodSky/pull/128)接入，本批修正跨页工作状态接缝及异常链接恢复，不改变地点、定位或云端范围。

## 缺陷与行为

1. 手动打卡控制器原返回`hasDraft/hasPending`，统一runtime读取`draft/pending`，导致原生离开提醒能看到待确认操作，而统一退出/更新/返回检查漏掉。本批改为统一字段，隐藏界面后仍报告真正的待确认操作，卸载后释放；不靠`busy`显示值猜测结果。
2. `App.onPageNotFound`原直接跳首页；现在复用已有`goHome`：有未确认写入时先留在当前页，未保存草稿先确认，取消可继续编辑。弹窗确认时重新检查是否已有写入。重复恢复只保留一个确认；应用隐藏、重回前台、进入朋友圈单页时使旧确认失效。干净页面可返回首页，导航失败有中文提示且可重试。

首页MoodSky表头、普通页面中文和四个标签不变。没有新增界面装饰、定位、真实数据操作或发布流程。

## 验证

- 实际Campus Page接入controller、runtime与goHome的合成回归，先复现统一检测`false`、预期`true`，修复后检查可见/隐藏、跟踪页面和卸载；原失败日志保留。
- 七个实际App+goHome回归，在原App均失败；修复后覆盖草稿取消/确认、重复触发、未知写入、弹窗期间新写入、前后台旧回调、导航失败与朋友圈单页。
- 准备共享源码后完整1287项通过；29份维护文档/466本地链接通过。此次无模板/样式变更，不将前一批原生编译和模拟器截图计作本批新证据；本批没有执行真机、云端写入或独立验收。
