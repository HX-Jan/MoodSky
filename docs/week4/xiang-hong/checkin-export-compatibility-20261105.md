# H04 打卡导出校验与格式兼容（11月5日）

本批基于main / 2588330276dc7a6cca994af5a5b589e0d527778c，只修改纯导出格式化器。基本打卡仍按用户自行前往、点击完成设计，无定位或到达核验。

## 实际修复

现有checkins格式会接受同地点同日重复行，也未检查完成时间是否属于该北京时间日期。本批在生成文件前拒绝重复、无效日期或时间与日期不符的来源，避免生成看似完整的错误文件。

同时接收Qinghan [PR130](https://github.com/HX-Jan/MoodSky/pull/130) / b83b1190560ff113809f6217d8e99327bcf07fcf导出层的campusCheckins扁平快照：每行必须有本人ownerId、placeId、真实date、有效UTC completedAt、placeName及selfReported:true。只投影公开的打卡字段，内部身份和请求信息不进入文件，输入对象保持原样。

统一输出data.checkins，保留旧快照的地点名与“用户自报完成”。仅有原checkins来源时维持原输出字段；两个来源同时存在时，同地点同日且完成时间一致只输出一次，不同则返回CONFLICT，不擅自选择或覆盖。合并后的总量仍受maxRecords约束，不截断。Markdown复用现有转义。
