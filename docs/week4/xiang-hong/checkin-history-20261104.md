# 本人打卡记录

从main `958bd8040d652a5a6f97217ff6fb0b23271c72b4`接续基本手动打卡。校园页增加“我的打卡”折叠入口，用户可查看本人记录、日期和北京时间。主流程仍是自行到达后点击“完成打卡”，不获取或核查位置，不增加核验材料、地图或照片步骤。界面沿用既有纸色、中文字体和绿色按钮；折叠入口至少44px，保持推荐与完成按钮的层级。

## 接口与保护

`campus.checkinHistory`为私有只读action，payload仅允许可选`cursor`。每次最多10条，按`date`倒序、同日`placeId`正序返回`{items,nextCursor}`；末页游标为null。游标只有日期/地点位置，不授权身份；请求所属账号由可信服务端会话决定，始终加入ownerId过滤和与注销/写入共用的账号事务围栏。原打卡的同日去重、回执跨午夜重试和来源修订不变，历史读取不推进导出修订。

翻页中锁定重复操作，失败保留已有内容和相同翻页位置；重复记录、乱序或循环游标不追加。页面隐藏或切号立即清空私人历史，旧响应不能复活。历史只读加载不阻止退出/更新；结果未知的打卡写入继续通过统一pending状态保护。

补齐当前日/历史读取和写入的身份拒绝处理：UNAUTHENTICATED、ACCOUNT_DISABLED、FORBIDDEN立即清空绑定及旧私人完成状态，不在停用后保留原账号界面。一个新增写入拒绝回归先复现旧绑定仍在，再修正通过；保留失败日志，不用原单模块通过代替本次组合验证。
