# W4 Z04 静态装饰候选接入

承接W3 Z05。核心功能稳定后，按H03/JQ03约束复测静态装饰的选择、读取、关闭与重置：仅静态贴纸与静态背景，不新增动画、不新增交互玩法。

## 现有能力

- 目录：`modules/review/demo-data.js`中的`STICKER_CATALOG`（6枚）与`BACKGROUND_CATALOG`（2张）。
- 上限：`LIMITS.staticStickers=6`、`LIMITS.staticBackgrounds=2`。
- 页面：`miniprogram/pages/universe/index.js`提供添加贴纸、关闭/开启装饰、重置、模拟素材失败与降级提示。
- 版本：装饰带`version`，写入需带`expectedVersion`，冲突返回`CONFLICT`。

本轮未改动上述业务实现，只做复测与记录。

| 输入                                                                                                | 期望                           | 实际 |

| 2枚贴纸（`STICKER_STAR`+指向10-16记录的`STICKER_MOON`）+`BACKGROUND_SKY_NIGHT`，`expectedVersion=0` | `version=1`、贴纸2枚、背景生效 | 通过 |

| 同一贴纸重复添加                                                                                    | `INVALID_INPUT`                | 通过 |
| 贴纸指向其它月份记录                                                                                | `INVALID_INPUT`                | 通过 |
| 未知背景`BACKGROUND_SPACE`                                                                          | `INVALID_INPUT`                | 通过 |
| 6枚贴纸再加1枚指向记录的贴纸（超过6枚上限）                                                         | `INVALID_INPUT`                | 通过 |

## 撤回与素材失效

| 场景             | 操作                              | 期望                                                    | 实际 |
| ---------------- | --------------------------------- | ------------------------------------------------------- | ---- |
| 目标记录被删除   | 删除10-16记录后重新读取装饰       | 指向该记录的贴纸被过滤，仅保留未绑定贴纸；`version`不变 | 通过 |
| 重置             | `reset`带当前版本                 | `version`加1、贴纸清空、背景为`null`                    | 通过 |
| 重置未装饰的月份 | 对9月`reset`，`expectedVersion=0` | 仍为`version=0`、空贴纸，不产生新版本                   | 通过 |

素材撤回采用“过滤失效目标”而非整体清除，因此同一月份里其它贴纸不受影响，也不会因一次删除而改写版本。

## 读取失败与加载失败回退

| 场景           | 注入                             | 期望                                                                                | 实际 |
| -------------- | -------------------------------- | ----------------------------------------------------------------------------------- | ---- |
| 装饰读取失败   | `decorations`抛出`NETWORK_ERROR` | 月历记录数不变、`calendarError`为空、装饰提示含“读取失败/降级”、贴纸为空、背景为空  | 通过 |
| 素材加载失败   | 已有1枚贴纸后模拟素材失败        | `decorationFailed=true`、贴纸全部`degraded`且标题为“素材未加载”、背景显示“默认背景” | 通过 |
| 失败时核心数据 | 同上                             | 记录数与已记录日期格不变，月历`weeks`中不出现降级文案                               | 通过 |
| 关闭装饰       | `onToggleDecoration`             | `decorationEnabled=false`、提示含“关闭”、本地偏好为`false`，记录数据版本仍前进      | 通过 |
| 重新开启       | 再次`onToggleDecoration`         | `decorationEnabled=true`、提示含“开启”                                              | 通过 |

装饰失败只影响装饰层，月历与回顾记录照常可读，符合“素材降级不影响核心功能”。

## 无动画与新玩法检查

- Z05用例对月历、详情、统计、宇宙四个页面样式做静态检查：不含`animation:`、`@keyframes`、`transition:`。
- 装饰操作只有添加、关闭/开启、重置与模拟失败，均为既有按钮，未新增拖拽、动效或新玩法。

## 阻塞（B-03）

`miniprogram/assets`当前只有`assets/jiaqi/`下的天气与导航图标，不存在`STICKER_*`或`BACKGROUND_*`素材文件，也没有JQ03素材目录规范落地。因此：

- 无法验证“正式素材”的实际组合效果与图片加载失败；
- 现行验证只覆盖合成候选的标识、上限、撤回、读取失败与素材失败降级。

解除条件：H03/JQ03提供素材与目录规范，且素材进入`miniprogram/assets`后，按上表重跑一遍组合与失效矩阵。该阻塞不影响回顾与记录功能正常使用。
