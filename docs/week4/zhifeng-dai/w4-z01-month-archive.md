# W4 Z01 月历档案与详情复测

承接W3 Z01/Z02。目标是用正式读取链路复测月历档案与详情，覆盖空月、跨月、排序、旧ID兼容、读取失败、卡片正文默认隐藏六种场景，并明确区分“错误态”与“无记录态”。

## 验证方式

- 档案页与详情页直接加载`miniprogram/pages/review/month/index.js`、`miniprogram/pages/review/detail/index.js`，通过`vm`注入`Page`与`wx`，不复制页面逻辑。
- demo模式注入`modules/review/demo-store.js`与`modules/review/demo-service.js`，云模式注入`modules/review/reader.js`，同时把demo服务与demo存储替换为“调用即计数并抛错”的替身，用于证明失败路径没有回填演示内容。
- 用例：[tests/week4-review-zhifeng.test.js](../../../tests/week4-review-zhifeng.test.js)第1、2项。

## 六场景记录

| 场景             | 输入                                                            | 期望                                                                          | 实际 |
| ---------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------- | ---- |
| 空月             | 数据只有9月与10月，访问`2026-08`                                | `recordCount=0`、`cards`为空、`error`为空串                                   | 通过 |
| 跨月             | 9月2条、10月4条                                                 | 9月只出9月卡片（2条），10月只出10月卡片（4条）                                | 通过 |
| 排序             | 10月：10-01、10-12、10-16、10-18                                | 卡片按日期倒序：`2026-10-18`→`2026-10-16`→`2026-10-12`→`2026-10-01`           | 通过 |
| 旧ID兼容         | 详情以`date=2026-10-16&id=z01_oct_16`进入；随后该日被重建为新ID | 进入时`phase=ready`；重建后`phase=stale`，正文清空，且不出现旧自定义名称      | 通过 |
| 读取失败         | 云模式`reader.monthArchive`抛出`NETWORK_ERROR`                  | `loading=false`、`error=连接失败，请重新读取。`、`recordCount=0`、`cards`为空 | 通过 |
| 卡片正文默认隐藏 | 任何月份的列表                                                  | `cardTextPreview=false`，卡片对象不含`text`字段，序列化后不含正文             | 通过 |

## 错误态与无记录态的区分

| 状态     | 判据                          | 页面表现                         |
| -------- | ----------------------------- | -------------------------------- |
| 无记录态 | `recordCount=0`且`error===''` | 空月提示，无错误文案、无演示卡片 |
| 错误态   | `error!==''`，记录数同样为0   | 显示错误文案与重试入口           |

用例对两类状态分别断言，避免把“读取失败”渲染成“这个月没有记录”。

## 读取失败不回填演示内容

云模式用例把demo服务与demo存储包成抛错替身并计数：`demoReads()`必须为0，且页面数据序列化后不含`SYNTHETIC`或“合成演示”。因此真实读取失败时页面只有错误态，没有任何演示回填。
