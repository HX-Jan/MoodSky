# W4 Z05 卡片与移动端展示检查

核对七天气图标、长`CUSTOM`名称、字体放大适配与空态展示，并确认素材加载失败时不影响核心数据阅读。本文件记录已落地的静态证据与尚未解决的真机项。

## 七天气图标

| 天气          | 图标映射 | 页面表现                        |
| ------------- | -------- | ------------------------------- |
| SUNNY         | 有       | 月历、详情、统计均取`ICONS`映射 |
| PARTLY_CLOUDY | 有       | 同上                            |
| CLOUDY        | 有       | 同上                            |
| RAINY         | 有       | 同上                            |
| STORMY        | 有       | 同上                            |
| TYPHOON       | 有       | 同上                            |
| CUSTOM        | 🌈       | 与`weatherName`一起显示         |

`WEATHER_TYPES`顺序为`SUNNY,PARTLY_CLOUDY,CLOUDY,RAINY,STORMY,TYPHOON,CUSTOM`共7项，`ICONS`对每一项都返回非空字符串；不存在第8类天气。

## 长CUSTOM名称

- 用例使用20码点名称（等于`LIMITS.weatherNameCodePoints`上限），不做截断。
- 月历卡片`label`、详情`weatherLabel`、统计时间线行`label`都完整显示该名称，图标为`🌈`。
- 三处样式对长文本的处理：

| 页面     | 选择器                | 换行规则                                | 位置                                                                              |
| -------- | --------------------- | --------------------------------------- | --------------------------------------------------------------------------------- |
| 月历档案 | `.archive-card-label` | `word-break: break-all`                 | [month/index.wxss](../../../miniprogram/pages/review/month/index.wxss#L55)        |
| 详情     | `.detail-label`       | `word-break: break-all`                 | [detail/index.wxss](../../../miniprogram/pages/review/detail/index.wxss#L41)      |
| 统计     | `.timeline-label`     | `word-break: break-all` + `min-width:0` | [insights/index.wxss](../../../miniprogram/pages/review/insights/index.wxss#L121) |

## 字体放大适配

- 四个回顾相关样式（月历、详情、统计、宇宙）均未出现`font-size: <数字>px`，字号统一使用`rpx`，随屏幕与系统字号缩放。
- 长文本容器允许断行，避免放大后撑破单行。
- 限制：以上为本地样式静态检查，不代表Android/iOS原生端已覆盖，真机项见下文。

## 空态展示

| 场景       | 期望                                               | 实际 |
| ---------- | -------------------------------------------------- | ---- |
| 空月份     | `recordCount=0`、卡片为空、`error`为空串           | 通过 |
| 统计空窗口 | `distributionEmpty=true`、7行分布计数与百分比均为0 | 通过 |
| 时间线为空 | `timelineItems`为空                                | 通过 |
| 空态文案   | 留白提示，趋势提示“不足 3 条”，不含上升/下降/评分  | 通过 |

空态不生成任何合成天气记录，也不把“没有数据”渲染成好坏判断。

## 素材加载失败时核心数据可读

素材失败时装饰层降级为“素材未加载/默认背景”文字提示，月历记录数、已记录日期格与回顾记录均保持不变，详见[W4 Z04](w4-z04-static-decoration.md#读取失败与加载失败回退)。
