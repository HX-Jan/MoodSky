# W4 Z03 跨页刷新与切号复测

承接W3 Z04。复测修改、删除、重建、账号切换、账号停用与乱序响应六类情况，重点核对旧月份数据与详情缓存：已删除的正文和用户自定义名称不得从缓存中返回。

## 复测矩阵

用例：`tests/week4-review-zhifeng.test.js`第4、5项；后端为内存实现`tests/helpers/backend-client.js`，页面数据均为页面`setData`后的真实状态。

| 场景     | 操作                                             | 期望                                                                          | 实际 |
| -------- | ------------------------------------------------ | ----------------------------------------------------------------------------- | ---- |
| 修改     | 同日期再次保存产生新`id`与`weatherName`          | 月历卡片`id`为新记录、显示新名称；旧详情以旧`id`进入时`phase=stale`、正文为空 | 通过 |
| 删除     | `journal.delete`后各页重读                       | 月历`cards`为空、统计`timelineItems`为空、详情`phase=missing`、正文为空       | 通过 |
| 重建     | 删除后重新保存                                   | 新记录可读；旧名称与旧正文不出现在任何页面                                    | 通过 |
| 账号切换 | `setActor('b')`并接受新会话                      | 页面立即清除原账号名称与正文，`calendarError`提示登录状态已变化；重试后为0条  | 通过 |
| 账号停用 | `setActor('disabled')`                           | 月历`weeks`为空，提示含“停用”，不残留旧名称或正文                             | 通过 |
| 乱序响应 | 先发的月读取延迟返回另一月份数据，后发请求已成功 | 页面保持后发请求的月份与记录数，迟到响应被`_seq`丢弃                          | 通过 |

## 逐入口刷新验证记录

| 入口       | 触发方式        | 刷新结果                                             |
| ---------- | --------------- | ---------------------------------------------------- |
| 月历档案页 | `onRetry()`     | 重新读取档案；删除后`cards`为空，重建后首卡为新记录  |
| 详情页     | `onShow()`      | 删除后进入`missing`，正文为空；旧`id`始终进入`stale` |
| 详情页     | `onHide()`      | 正文、名称等私人内容立即清空                         |
| 统计页     | `onRetry()`     | 重新读取单快照；删除后`timelineItems`为空            |
| 宇宙月历页 | `onRetry()`     | 切号后清除旧账号视图并提示；停用后清空月历网格       |
| 宇宙月历页 | `onMonthPick()` | 按所选月份重读，迟到的旧响应不会覆盖当前月份         |

## 缓存清空功能验证

| 验证点               | 期望                                                       | 实际 |
| -------------------- | ---------------------------------------------------------- | ---- |
| 页面隐藏时的私人内容 | `onHide`后`text`为空，名称与正文均不残留                   | 通过 |
| 账号绑定变化         | 订阅到绑定变化即清空页面内容并给出提示，不等待下次`onShow` | 通过 |
| 删除后的详情         | 重进为`missing`，不回退至上一次正文                        | 通过 |
| 删除后的月历与统计   | 列表为空，不保留已删除卡片                                 | 通过 |
| 旧记录重建后的旧详情 | `stale`，不展示新正文，也不展示旧名称                      | 通过 |
| 装饰偏好（本地设置） | 关闭/开启状态保存在本地，仅影响装饰，不影响记录数据        | 通过 |
| 演示数据             | 云模式下demo读取计数为0，任何失效路径都不回填演示内容      | 通过 |

## 复核提示（Qizhen Cai）

独立复核建议按“删除→重进详情→刷新月历→刷新统计”的顺序走一遍，再切号观察旧名称是否残留；页面数据中不应出现被删正文或旧自定义名称。用例已把三类页面（月历、详情、统计）以及宇宙月历纳入断言。
