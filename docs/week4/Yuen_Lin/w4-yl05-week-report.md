- 固定 `main` 提交、归档哈希、锁文件和源码 tree 后再跑检查，避免把旧副本或移动的 `main` 当基线。
- 用官方归档时，`production-package` 等测试依赖 git 元数据；本地快照需明确标注，不能伪装成上游提交。
- 打包器只生成候选；`uploaded/deployed/phoneVerified` 都是 `false` 时，不能把候选包写成线上版本。
- 测试数量不是贡献指标；本轮 405/425 是 1398 的子集，不重复相加。
