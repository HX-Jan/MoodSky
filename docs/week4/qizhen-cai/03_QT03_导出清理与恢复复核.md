# W4 QT03 导出清理与恢复复核

## 复核目标

本次复核覆盖私人导出的账号绑定、数据变更失效、受限领取、账号停用竞争、幂等清理、
部分失败恢复、删除账本与公共资料保留。地点手动打卡、任务、偏好、收藏、纠错和装饰
均按其当前数据归属参与清理与导出边界检查。

## 生命周期核查结果

| 环节               | 预期                                                                | 本地结果 |
| ------------------ | ------------------------------------------------------------------- | -------- |
| 申请和领取         | 导出对象绑定到服务端账号和受限权限；错号、错 job 或篡改回执不能领取 | 通过     |
| 变更失效           | 数据修改、偏好修改、候选装饰更新和删除均使旧导出失效                | 通过     |
| 时间边界           | 本地时钟在 24 小时边界拒绝到期导出；回执到期不会重新授权            | 通过     |
| A/B 切换           | A 的迟到下载、清理进度和关闭结果不显示给 B，也不写入 B 的文件或状态 | 通过     |
| 停用和清理         | 关闭先建立受限进度，再清除本人私有对象；重复清理返回稳定结果        | 通过     |
| 部分失败           | 失败保留可恢复的原范围和原请求；不把未完成清理显示为完成            | 通过     |
| 公共资料与他人数据 | 公共地点、共享模板和 B 的对象保留；清理仅作用于 A 的私人对象        | 通过     |
| 删除账本恢复       | 账本重放维持已删/停用对象不可复活，恢复计划与执行器用例可复现       | 通过     |

## 当前安全行为

- 默认关闭的云业务入口保持明确的 `NOT_IMPLEMENTED`，不以空数据、固定成功或假完成
  代替真实执行器。
- `cleanup_status` 使用仅限对应 job 的受限回执；回执不是登录态，不能恢复停用账号。
- 清理统计以已提交的逐集合进度为基础；重复运行不改变既有累计结果。
- 私人投影不输出内部字段；校验失败、数据矛盾或未知结果均保留错误路径而非拼接为成功结果。
