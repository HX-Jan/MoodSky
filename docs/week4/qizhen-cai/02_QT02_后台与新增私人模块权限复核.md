# W4 QT02 后台与新增私人模块权限复核

## 复核对象

本次复核对象为校园推荐浏览、本人手动打卡和历史、收藏、纠错、私人任务，以及地点、
任务模板、支持资源和纠错审核等后台入口。检查同时覆盖接口门禁、页面调用与异步会话边界。

## 权限模型

| 标记 | 身份           | 允许范围                                     |
| ---- | -------------- | -------------------------------------------- |
| G    | 游客           | 公开校园资料浏览；不取得私人或运营权限       |
| A    | 普通账号 A     | 仅本人私人数据与本人操作                     |
| B    | 普通账号 B     | 仅本人私人数据与本人操作                     |
| D    | 已停用账号     | 私人操作、运营操作均被拒绝                   |
| O    | 活跃运营账号   | 仅经服务端 `operator_roles` 确认后的后台操作 |
| OD   | 已停用运营账号 | 不因旧角色、浏览器角色或 SDK 会话取得权限    |

## 本地矩阵结果

对 32 个已注册的 private/operator action × 6 种身份共执行 198 行门禁检查，
期望和实际全部匹配。完整逐行数据见
[local-permission-matrix.json](evidence/local-permission-matrix.json)。

| 入口类别                         | 游客                 | 普通账号            | 停用账号           | 活跃运营账号        | 停用运营账号       |
| -------------------------------- | -------------------- | ------------------- | ------------------ | ------------------- | ------------------ |
| 私人记录与回顾                   | `UNAUTHENTICATED`    | 到达受控业务入口    | `ACCOUNT_DISABLED` | 到达受控业务入口    | `ACCOUNT_DISABLED` |
| 私人导出、清理和状态回执         | 无有效受限回执即拒绝 | 按当前账号/回执绑定 | `ACCOUNT_DISABLED` | 按当前账号/回执绑定 | `ACCOUNT_DISABLED` |
| 后台地点、模板、资源与纠错       | `UNAUTHENTICATED`    | `FORBIDDEN`         | `ACCOUNT_DISABLED` | 到达受控业务入口    | `FORBIDDEN`        |
| 客户端伪造 owner、openid 或 role | 拒绝                 | 拒绝                | 拒绝               | 拒绝                | 拒绝               |

“到达受控业务入口”只表示该身份通过门禁，不表示默认云入口已经接通业务适配器；默认
关闭入口仍返回明确的 `NOT_IMPLEMENTED`，不会伪报保存或读取成功。

## 双层检查要点

- 服务端角色只来自可信身份解析和 `operator_roles`；浏览器或 SDK 中的角色字段不能授权。
- 运营端列表、详情、保存和重读覆盖普通用户、停用运营、伪造角色、冲突和网络错误。
- 页面在身份失效、切号或 SDK 会话过期时先清除私有草稿和旧结果，再阻止新的云请求。
- 校园公开资料与私人内容分开投影；纠错队列不向运营端暴露提交者身份；公共列表不返回日记字段。
- 同一会话内角色撤销后，下一次请求立即失去访问权；迟到认证或读取结果不能回填更新后的账号视图。

## 证据边界

本矩阵的身份、角色和仓储均为脱敏本地替身。真实 Web 登录回调、实际运营授权和第二个
真实用户的页面操作应以对应平台会话与操作记录单独保存，不与本地矩阵混写。
