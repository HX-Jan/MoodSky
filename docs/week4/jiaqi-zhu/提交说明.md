# 第四周 GitHub 提交说明

目标目录为 `docs/week4/jiaqi-zhu/`。若 11/05 已创建个人分支或 PR，将本包解压后更新同一分支的同名目录。首次提交可从团队的 `main` 新建 `codex/jiaqi-w4-design`，建议提交标题为 `docs(w4-jq): add design handoff and survey findings`。

1. 下载并解压新版压缩包。
2. 在个人分支打开 `docs/week4`，使用 **Add file → Upload files**，拖入解压后的整个 `jiaqi-zhu` 文件夹。上传列表应出现 `jiaqi-zhu/README.md` 等相对路径。
3. 提交后查看文件列表，再把 [PR_BODY.md](PR_BODY.md) 的内容用于指向团队 `main` 的 PR。已有 PR 会随原分支提交更新。
4. 只交一份报告时，可提交 [W4_Jiaqi_Zhu_交付报告.md](W4_Jiaqi_Zhu_交付报告.md)。素材和可复查的分题结果随完整目录一起提交。

原始 Excel 含 IP 和答卷元数据，保留在本地。压缩包用于交接，GitHub 上提交展开后的文件。
