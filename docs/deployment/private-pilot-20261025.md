# 本人受限云测试接入（2026-10-25）

状态：代码、本地联调及固定打包工具已完成；新的真实云写入和手机验收尚未执行。现有正式 moodsky 函数、备案前体验版 0.2.3.1025b 和原 H03 探针保持本轮开始时状态。

## 已实现

- 新增独立 `moodsky-private-pilot` 测试入口。闭合包即使配置了全部开关也不构造数据库；活动包必须同时满足指定操作者、当前调用的微信身份、AppID/环境匹配、指定测试日期、明确账号唯一索引验收及最长 24 小时有效配置。
- 不从客户端 userInfo/tcbContext 或函数进程中残留的 WX_OPENID 获取身份。仅解析本次平台第二参数中的 environment/environ；来源只允许 wx_client/wx_devtools，未知或缺失均拒绝，需先用闭合包在真实环境核对。
- 测试身份由服务器将实际微信身份转成加密伪名，创建带 `restricted-pilot-hmac-v1` 标记的测试账号。与正式账号分开，不存原始 OPENID，不迁移已有账号或日记，避免测试内容进入以后正式账号的统计。
- `account.session` 返回经验证账号的不可读范围标记。它不是内部账号 ID，也不是脱离微信身份即可使用的访问凭证。客户端仅在内存保留，账号变化/验证失败清空，迟到的验证不覆盖新会话。
- 测试函数的额外传输层固定为 `{request: 原有v1请求, sessionScope?: 范围标记}`。原 v1 信封仍只有 apiVersion/requestId/action/payload。原函数 moodsky 不使用该传输层。重试固定原函数、环境、请求与账号范围，服务端以本次微信身份重新校对，不能向另一账号重放。
- 记录、回顾和任务使用现有原生数据库适配、事务、账号围栏和回执。`tasks.mine` 是私人建议接口，返回当天状态，优先保留已选择的任务，最多三条；完成后重新读服务端，终态不再显示重新选择按钮。任务历史保持客户端 items 结构。
- 仅显式 `cloudFunctionName:moodsky-private-pilot`、`trustedSessionEnabled:true` 的独立预览包开启会话接入。普通云模式、现有内存演示和默认正式门禁保持原行为。预览的我的页面不加载合成账号缓存，不显示合成导出/注销按钮，连接成功不冒充保存成功。

## 打包与部署顺序

在干净的本地源码提交上运行：

```powershell
node scripts/package-private-pilot.js 'C:/Users/LENOVO/Desktop/软件工程/group_project/test-results/2026-10-25-private-pilot/package'
```

输出 `closed/moodsky-private-pilot`、`active/moodsky-private-pilot` 及独立手机预览 `client`，三文件哈希记入 manifest。预览包不得上传为现有体验版。构建复用已锁定依赖（原生 SDK 3.17.2、WX SDK 4.0.2），不引入新的版本。

1. 先确认同名测试函数不存在；如已存在，必须下载核对，不能覆盖他人函数。
2. 仅部署 closed 包，执行不写数据库的身份/健康诊断，核对当前调用来源和环境。此阶段不启用秘密、不写业务行。
3. 准备活动包与关闭包固定哈希、私人环境配置和测试范围，完成确认后才配置服务器并部署 active 包。位置权限、公开发布、后台资料、导出、注销和数据清理不在本次范围。
4. 在不超过 24 小时且限当天的窗口内，仅指定操作者测试。正文和自定义天气名称只接受为空或以合成开头的测试内容。任务目录读取已有启用数据；为空保持空态，不擅自发布示例模板。
5. 结束后重新部署 closed 包并下载核对。即使服务器变量仍保留，也不能重新开放访问；所有测试数据保留，后续清理另行确定，不删除旧记录。

## 服务器配置（均不能放进客户端或 Git）

| 名称                                 | 含义                                                           |
| ------------------------------------ | -------------------------------------------------------------- |
| MOODSKY_PRIVATE_PILOT_ENABLED        | 字符串 true，仅活动包识别                                      |
| MOODSKY_PILOT_ACCOUNT_INDEX_VERIFIED | 重新核对 accounts 的 openid 唯一索引后才填 true                |
| MOODSKY_PILOT_OPERATOR_FINGERPRINT   | 真实调用所得的本人指纹，不填原始 OPENID                        |
| MOODSKY_PILOT_RECEIPT_KEY_BASE64     | 新生成的 32 字节测试密钥，不能使用测试源码常量或复用为正式密钥 |
| MOODSKY_PILOT_TEST_DATE              | 实际测试当天 YYYY-MM-DD                                        |
| MOODSKY_PILOT_EXPIRES_AT             | 固定 UTC 到期时刻，必须未来且距服务器当前时刻不超过 24 小时    |

密钥在本次测试期间保持固定，不在超时后临时换钥或新建请求绕过回执。变量缺失、过期、日期变化或指纹不匹配时，在业务数据库访问前拒绝。实际写入可能涉及 accounts/journals/request_receipts/deletion_markers/task_history；task_templates 和回顾所需集合只读，不新增索引、权限或公开文件。
