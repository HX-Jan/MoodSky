## P07 有持续记录习惯的学生

- 时间：2026年10月13日19:00—19:15
- 背景：20岁，大二，每周使用手机备忘录记录生活三至四次。

| 主题       | 访谈回答                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------ |
| 记录习惯   | 一般晚上才想起来写。有时候只是几句话，忙的时候就不写了，隔几天再补已经记不清。             |
| 天气表达   | 只选一个天气会比较快，但有时心情比较复杂，希望还能加一句自己的解释。                       |
| 私人范围   | 我希望默认只有自己能看。看到“普通运营不可见”，我还会想，那是不是有其他管理人员能看到？     |
| 月份回顾   | 我会想看看考试周或者某个月的记录，按月份找比一直往下翻方便。                               |
| 地点和任务 | 地点信息对我有用，小任务可以有，但不要因为我选了雨天就一直给我推任务。                     |
| 导出与注销 | 导出最好按日期排列，保留文字和标签。注销时要说明账号什么时候不能用了、数据什么时候清理完。 |
| 模拟气象   | 只要明显写着模拟，我就会把它当功能示例，不会当成学校的实际情况。                           |

分析与待验证建议：天气允许独立保存，正文可选；隐私说明解释云服务的受控存储与处理；导出内容按日期组织。关联UW3-F01、F02、F08、F21、F22。

## P08 偶尔记录且容易中断的学生

- 时间：2026年10月13日20:10—20:25
- 背景：19岁，大一，偶尔记录重要事件，没有固定写日记的习惯。

| 主题       | 访谈回答                                                               |
| ---------- | ---------------------------------------------------------------------- |
| 记录习惯   | 我试过每天写，但坚持不了。漏了几天之后，就不太想继续打开。             |
| 天气表达   | 选一个天气就能保存，我可能愿意用。如果必须写字，就会拖到最后不写。     |
| 私人范围   | 我最担心点保存之后别人能看到。保存按钮附近有一句说明会更安心。         |
| 月份回顾   | 没写的日子就空着吧，不要显示我断了多少天。                             |
| 地点和任务 | 任务可以很小，比如出去走一下，但我希望能直接跳过，也不用说明理由。     |
| 导出与注销 | 导出功能可能用得少。注销时我更关心是不是点完就不能再登录看以前的东西。 |
| 模拟气象   | 如果模拟说明放得很小，我可能只看图，就以为是大家填出来的。             |

分析与待验证建议：不强制正文，不设置连续记录惩罚；缺失日期留白；跳过任务无需解释；模拟图表附近持续展示说明。关联UW3-F01、F05、F18、F24。

## P09 重视隐私且很少记录感受的学生

- 时间：2026年10月14日12:30—12:45
- 背景：21岁，大三，较少在应用中记录私人感受，对账号权限和信息保存较敏感。

| 主题       | 访谈回答                                                                       |
| ---------- | ------------------------------------------------------------------------------ |
| 记录习惯   | 有些事情我只记在脑子里，不太想放到软件里，主要是不知道以后谁能看到。           |
| 天气表达   | 天气比直接写心情更容易接受，不过连续很多天的天气也能看出一些私人情况。         |
| 私人范围   | 不只是正文，标签和记录时间我也不希望别人看到。后台能不能查看这些，需要讲清楚。 |
| 月份回顾   | 列表最好先不显示正文。我在公共场合打开时，不想一下子露出很多文字。             |
| 地点和任务 | 可以根据我这一次选的条件找地方，不希望偷偷分析我以前的记录。                   |
| 导出与注销 | 如果下载链接被复制，别人能不能打开？注销后，之前生成的链接还有效吗？           |
| 模拟气象   | 固定模拟可以，但不要把我今天选的天气加进去，哪怕说是匿名统计。                 |

分析与待验证建议：正文列表预览默认关闭；任务推荐仅使用本次偏好；验证下载凭证和注销后的失效；模拟预览与真实记录完全分离。关联UW3-F09、F17、F21、F22、F23、F24。

- 时间：2026年10月14日18:40—18:55
- 背景：20岁，大二，课余常在校园寻找自习、休息或散步地点。

| 主题       | 访谈回答                                                                             |
| ---------- | ------------------------------------------------------------------------------------ |
| 记录习惯   | 一般遇到特别开心或者烦的事情才会记，普通的一天不太会写。                             |
| 天气表达   | 天气比较直观，最好图标旁边有名字，不然有两个图长得像，我可能分不清。                 |
| 私人范围   | 我会默认日记是自己的，但校园地点应该是大家都能看的，两种内容最好区分清楚。           |
| 月份回顾   | 我不需要复杂的图，能找到以前某一天写了什么就够了。                                   |
| 地点和任务 | 我最关心现在开不开、能不能坐、吵不吵。如果不授权定位，也希望可以自己选地点。         |
| 导出与注销 | 收藏的地点如果也会被清理，注销前应该提醒一下。其他同学不能因为我注销就看不到地点吧？ |
| 模拟气象   | 我会把它当展示效果，但地点如果也是模拟的，一定要另外标明，不能让我照着去找。         |

- 时间：2026年10月15日19:20—19:35
- 背景：22岁，大四，学习事务较多，偏好步骤少、无需持续维护的工具。

| 主题       | 访谈回答                                                                       |
| ---------- | ------------------------------------------------------------------------------ |
| 记录习惯   | 忙的时候只想快速留个标记，不想填很多项，也不希望一打开就有一堆提示。           |
| 天气表达   | 选天气、保存，两步就差不多。想多写的时候再展开其他内容。                       |
| 私人范围   | 保存成功要明确告诉我，网络不好时也要说清楚，不然我会一直点。                   |
| 月份回顾   | 我可能会在一个阶段结束后回头看，不一定每天看统计。                             |
| 地点和任务 | 任务建议两三个就够了。没做完也不要一直催，更不要提示我心情因为没做任务变差了。 |
| 导出与注销 | 导出正在处理的时候，最好告诉我现在是什么状态。失败了就让我重试，不要一直转圈。 |
| 模拟气象   | 我不会因为模拟图里的晴天多就判断大家状态好，前提是说明足够明显。               |

## P12 关注月份回顾和记录保留的学生

- 时间：2026年10月16日12:10—12:25
- 背景：21岁，大三，偶尔翻看旧照片和备忘录，希望按时间整理个人记录。

| 主题       | 访谈回答                                                                         |
| ---------- | -------------------------------------------------------------------------------- |
| 记录习惯   | 我不一定每天写，但写过的东西会想留着。有时想找某个月的记录，翻起来很麻烦。       |
| 天气表达   | 天气可以帮我认出那一天，但我还是希望打开后能看见自己当时写的话。                 |
| 私人范围   | 如果天气卡片很好看，我也不希望它自动变成别人能看的主页。                         |
| 月份回顾   | 先选年和月，再看那个月的卡片比较清楚。没有记录的月份直接说没有就行。             |
| 地点和任务 | 地点可以收藏。任务历史只给自己看就好，我不需要和别人比较。                       |
| 导出与注销 | 删除一条记录后，月历和卡片里也应该一起消失。注销前可以提醒我先导出，但不要强迫。 |
| 模拟气象   | 我能接受示意图，不过最好一直有标识，不能只在第一次打开时解释。                   |

分析与待验证建议：提供清晰的年/月入口和空月份状态；卡片不自动公开；删除同步所有派生视图；注销前提供可跳过的导出提示。关联UW3-F04、F08、F09、F19、F22、F23。
