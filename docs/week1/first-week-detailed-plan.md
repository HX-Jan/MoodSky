# MoodSky 第一周成员任务

第一周任务按12名成员分别列出。每人完成本人五项任务，并提交成果、检查记录和需要交接的事项。成员按前置资料是否就绪自行安排执行顺序。

本版保留已经确认的职责、技术工具、交付物和验收要求，取消每日安排和分项日期。第一周以环境及身份验证、交互演示、接口与数据设计和测试准备为主，正式记录写入闭环在第二周推进。

## 1 共同要求

复用现有原生微信小程序、Node.js云函数、CloudBase、四页骨架、模块service、请求封装、共享常量和自动检查。后台Web登录和实际云配置根据验证结果确定。

每人阅读需求与本人模块，确认可投入时间，提交个人周报和后续任务估点，并提供一个自愿受访学生的招募线索。Jiaqi统一去重协调，Jiaqi与Qizhen Cai各执行六次真实访谈。

代码按现有分支与PR流程提交；共享接口、数据库和导航调整需要对应负责人共同复核。成果记录放在docs/week1/本人目录。AI任务提示词按姓名提供，每人一段，依照本计划的完整要求执行。

合成演示、本地测试、真实云端与真机结果分别记录。未实现、未测和缺输入的内容保留明确状态，不填虚构成功。遇到阻塞说明所需资料或权限、尝试结果、接收负责人和仍可继续的工作。
