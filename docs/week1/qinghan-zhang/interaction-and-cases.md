# 交互草图与验收步骤

这是页面交互结构草图，不是微信开发者工具截图。实际页面视觉、布局和原生控件兼容性尚未验证。

## 页面草图

首次 Campus → “暂无经过核验的地点资料” + [开始合成演示]

[开始合成演示] → 合成标识/固定参考日期 → [校区筛选] [标签筛选]
→ 卡片（名称 / 状态 / 开放信息 / 无障碍 / 核验日期）→ [下一页] 或无结果
→ 点击卡片 → 详情（地址 / 开放信息 / 无障碍 / 核验日期 / 来源）
→ [收藏 / 取消收藏（本地演示）] + [主动打开地图（合成数据禁用）]
→ [模拟地图失败] → 失败提示 + [返回列表]，原筛选和列表保留
→ 纠错输入 + 码点计数 → [演示提交审核] → 待审核 → [模拟通过] / [模拟驳回]
→ [退出并清除演示] → 未核验空态

独立定位卡片：[尝试定位] → 隐私授权（平台提供时）→ 定位授权/失败 → 继续浏览。
支持资源卡片：未核验空态 → [查看接入状态] → 明确真实接口未接入。
