# W1 Z02 · 月历可点击演示

负责人：Zhifeng Dai · 2026-10-16

## 实现范围

- 页面：`miniprogram/pages/universe/index`（Weather Universe，tab 页）
- 数据：`miniprogram/modules/review/demo-data.js`（合成种子）、`demo-store.js`（内存数据源）、`demo-service.js`（`review.calendar` 演示实现）
- 开启条件：`journalDemo: true` 且 `cloudEnabled: false`（与 Today 演示一致）；未开启时保持原空态，不显示模拟数据

## 覆盖场景

| 场景             | 演示数据                                                                      | 验证方式                                    |
| ---------------- | ----------------------------------------------------------------------------- | ------------------------------------------- |
| 有记录日期       | 2026-10：10-01 ⛅晴间多云、10-09 ☀晴天、10-12 ☁阴天、10-15 ⛈暴雨、10-16 ☂雨天 | 月历点击进入详情                            |
| 无记录日期       | 任意空白日期（如 10-10）                                                      | 仅显示日期数字，无天气标识、不可点击        |
| 真实阴天 vs 空白 | 10-12 为真实 CLOUDY 记录                                                      | 用于证明空白日期不会被误识别为阴天          |
| 月份切换         | ‹ › 按钮 + 月份选择器（picker mode=date fields=month）                        | 快速切换时丢弃迟到响应（视图代次守卫，R15） |
| 跨月场景样例     | 2026-09-27 ☀、2026-09-30 ☂（九月末）与 10-01 ⛅（十月初）连续分布             | 9 月 ↔ 10 月往返切换，格位与星期对齐准确    |
| 全空月份样例     | 2026-08 无任何记录                                                            | 网格正常排布 + “本月暂无记录”空态文案       |

日期与天气配套文字：每条种子记录都有 `weather` 与对应文字（如“合成演示：傍晚跑了三公里，天很晴。”），月历单元格显示图标 + 天气文字标签。

## 交互逻辑

1. 点击有记录日期 → `navigateTo /pages/review/detail/index?month&date&id`（详情页复核 entryId）。
2. 点击空日期 → 事件处理器中无 id 直接忽略，保持留白。
3. 月份切换 → 重新请求 `review.calendar(月份)`；`calendarBusy` 期间禁止重复操作；每次请求携带自增 token，迟到响应不覆盖当前月份（R15）。
4. 日期格位渲染：`buildWeeks` 使用 UTC 计算每月 1 日星期与天数，周日开头，尾部补白，保证任意月份格位准确。
