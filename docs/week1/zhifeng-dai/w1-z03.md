# W1 Z03 · 月份档案与卡片演示

负责人：Zhifeng Dai · 2026-10-16

## 实现范围

| 页面                     | 路径                         | 内容                                                                                                                                  |
| ------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 月份列表（月份档案入口） | `pages/review/archive/index` | 有记录月份 + 记录条数；全空月份样例 2026-08 以虚线样式列出（标注“全空月份样例”）                                                      |
| 指定月份档案页           | `pages/review/month/index`   | 该月卡片列表：每张卡片仅显示“日期（含星期）+ 天气图标与文字 + 查看详情”；页头显示“共 N 条记录 · 卡片默认只显示日期与天气，不展示正文” |
| 记录详情页               | `pages/review/detail/index`  | 本人全文展示：日期、天气、标签、正文、版本与最近更新时间                                                                              |

数据来源：`review.monthArchive` 演示实现——`cards[]{id,date,weather}` 按业务日期降序，数据层物理上不含 `text/tags`；`cardTextPreview: false` 显式声明默认响应不返回正文。

## 完整跳转路径

```text
Universe（月历 tab）
  → 月份档案入口 → /pages/review/archive/index（月份列表）
      → 点击 2026年10月 → /pages/review/month/index?month=2026-10
          → 点击某张卡片（如 2026-10-15）→ /pages/review/detail/index?month=2026-10&date=2026-10-15&id=demo_20261015
              → 展示全文；记录已删除/已重建时显示空态或“已更新，请返回刷新”
```

空月路径：月份列表 → 2026年8月 → 档案页显示“本月暂无记录”空态，不渲染任何卡片。

## 卡片默认内容边界（验收点）

- 卡片渲染的字段：`dateLabel`、`icon`、`label`（天气文字）——WXML 中不出现 `{{item.text}}`、`{{item.tags}}`。
- 服务层断言（`tests/review-demo.test.js`）：卡片对象不携带 `text`/`tags` 键；月历与卡片的记录 id 集合一致（同一来源）。
- “从月份入口直接定位到指定记录”（W1 Z05 要求）即本路径：卡片点击携带 `month/date/entryId`，详情页读取该日最新记录并核对 id，防止打开旧卡。

## 验证记录

- `npm run check` 全绿；微开发者工具人工路径：月份列表 → 月份档案 → 卡片 → 详情 全程可走通；返回后列表状态保持。
- 详情页三态验证：正常态（全文）、missing（记录不存在）、stale（entryId 不一致）。
