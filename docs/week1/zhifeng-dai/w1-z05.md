## 1. 刷新与失效事件清单

触发点：Today 页 `journal.save()` / `confirmDelete()` 成功后，controller 触发 `onChanged({date, kind})`，`kind ∈ {'saved','deleted'}`。

事件流（演示架构，真实架构中由服务端数据与接口约定完成同等效果）：

```text
Today 保存/编辑/删除成功
  → onChanged({date, kind})
  → Today 页读取该日最新记录（journal.get 语义）
  → reviewStore.applyChange({date, kind, entry})   // sourceRevision 递增
  → 发布“回顾失效事件”（store.subscribe）
  → 订阅页面刷新：
       Universe 月历（当前月份重新请求 review.calendar + 装饰状态）
       月份列表（重新聚合月份与条数）
       月份档案（当月卡片重新请求 review.monthArchive）
       分布与时间线（当前窗口重新请求，live 数据源）
       记录详情（订阅后按日期重读并核对 entryId）
```

| 场景                     | 月历                            | 月份档案/卡片          | 分布/时间线                         | 详情页                                                |
| ------------------------ | ------------------------------- | ---------------------- | ----------------------------------- | ----------------------------------------------------- |
| 保存新记录               | 该日出现天气标识，recordCount+1 | 该月卡片+1             | 记录落在窗口内则计数+1              | —                                                     |
| 编辑（改天气/标签/正文） | 该日天气标识与文字立即更新      | 卡片日期/天气更新      | 天气分类计数迁移                    | 重读显示新全文                                        |
| 删除                     | 该日恢复留白（非阴天）          | 卡片移除；空月显示空态 | 计数-1；跨过 3 条门槛时趋势提示变化 | 显示“这一天没有可展示的记录”                          |
| 删除后同日重建           | entryId 更换                    | 新卡片                 | 正常计入                            | 旧链接显示“该日期的记录已更新，请返回刷新”（R06/R07） |

并发与失效保护：

- **迟到响应不覆盖新视图**（R15）：月历/档案/详情/统计的每次请求携带自增 token，响应回来先比对 token。
- **sourceRevision** 随每次数据源变化递增，仅用于比较新旧、不是授权凭证。
- 装饰关联旧 `entryId` 时随记录删除立即过滤；独立月份装饰不受单日删除影响（有测试覆盖）。

## 2. 装饰关闭、素材失败、重置的降级状态

在 Universe 装饰卡片提供四个演示按钮，全部规则已实现并测试：

| 操作             | 降级行为                                                             | 不变项                                                         |
| ---------------- | -------------------------------------------------------------------- | -------------------------------------------------------------- |
| 关闭装饰（偏好） | 隐藏装饰内容，显示“装饰已关闭”说明                                   | **不删除装饰配置、不改日记**；月历与记录展示不受影响（H04 §5） |
| 模拟素材加载失败 | 贴纸芯片显示“素材未加载（已降级）”、背景显示“默认背景”，虚线降级样式 | 天气文字照常显示；月历、档案、详情全部可用；无崩溃无空白       |
| 恢复素材         | 恢复合成素材标识展示                                                 | 数据层原始 stickerId 保留（降级只影响展示层）                  |
| 重置装饰         | 贴纸清空、背景置空、版本推进                                         | 日记与偏好不受影响；无配置月份重置不创建文档、不推进版本       |

装饰版本控制：replace/reset 必须携带 `expectedVersion`，不一致返回 CONFLICT，页面自动重读最新状态并提示重试（演示按钮添加贴纸即演示该流程）。

## 3. 从月份入口直接定位指定记录

路径：月份档案卡片 → `/pages/review/detail/index?month&date&id`。详情页按日期重读 + 核对 id，三种结果：正常展示全文 / 记录不存在 / id 不一致提示返回刷新。卡片列表**不渲染任何正文**（数据层即不含 text，详见 w1-z03）。
