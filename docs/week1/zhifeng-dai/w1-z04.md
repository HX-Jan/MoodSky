## 三项统计展示规则（实现即规范）

| 规则                       | 实现                                                                                                                                             | 校验                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 1. 实际记录数作为统计分母  | 分布条目显示 `x/recordCount 条`（如 2/3 条），分母**不是**窗口天数；五类天气计数为 0 也保留                                                      | 测试断言 `sum(bins.count) === recordCount` 且 `recordCount !== windowDays` |
| 2. 缺失日期位置留空        | 时间线只渲染有记录的日期（业务日期降序），不合成天气；页面显示“窗口 N 天 · 记录 M 条 · 其余 K 天留白”                                            | 样例 B 90 天窗口：90 天中仅 2 条，其余 88 天留白                           |
| 3. 不足 3 条不输出趋势结论 | `trendEligible = recordCount >= 3`（`LIMITS.minimumTrendEntries`）；页面文案区分“达到门槛（仅数量）”与“不足 3 条”，两种情况都不输出上升/下降结论 | 样例 A/B false、样例 C true                                                |

## 样例数据集（固定时钟 2026-10-15）

| 样例             | 记录                       | 7 天窗口（10-09~10-15）       | 30 天窗口                         | 90 天窗口 |
| ---------------- | -------------------------- | ----------------------------- | --------------------------------- | --------- |
| A · 0 条         | 无                         | 0 条 · 中性空态（不计算 0/0） | 0 条                              | 0 条      |
| B · 2 条（跨月） | 09-20 ☀、10-12 ☂           | 1 条（☂ 1/1 条）              | 2 条（☀ 1/2、☂ 1/2，跨月含 9 月） | 2 条      |
| C · 3 条         | 10-09 ☀、10-12 ☂、10-15 ⛅ | 3 条（各 1，1/3 × 3）         | 3 条                              | 3 条      |

趋势门槛：A/B 任何窗口均不输出趋势结论；C 达到 3 条门槛，页面仅提示“已达到数量门槛，不输出结论”。

## 口径核对方法（供 Yuen、Xiang Hong）

1. 打开 分布与时间线 → 选择“样例 B · 2 条（跨月）” → 切换 7/30/90 天：
   - 7 天 = 1 条、30/90 天 = 2 条（9 月记录只在 ≥30 天窗口出现）→ 验证窗口切片与跨月；
   - 分布行显示 `1/2 条` 类文案 → 验证分母口径；
   - 页脚显示“其余 K 天留白” → 验证留白规则。
2. 选择“样例 C · 3 条” → 趋势提示出现但无结论 → 验证门槛规则。
3. 自动化：`node --test tests/review-demo.test.js`（11 项断言覆盖上表全部口径）。

## 已知边界（与 w1-h04 对齐）

- 分布与时间线为两次查询，不声称原子快照（H04 §4 已登记缺口）。
- 窗口计算使用业务日期（Asia/Shanghai），跨夏令时场景不适用（业务全在中国时区）。
