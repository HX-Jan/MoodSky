# 当前记录接口字段对照（W2-YF01 整合修订）

2026-10-25。当前基线为已整合的七天气实现；本表按 shared/constants、shared/validation、shared/types 与 W2 契约清单核对，属于源码对照，页面负责人共同确认待回传。原 PR #7 五天气稿保留于 PR #51 原始提交，不作为当前契约。

| journal.upsert 字段 | 当前规则                                                           |
| ------------------- | ------------------------------------------------------------------ |
| date                | 北京时间 YYYY-MM-DD；新建限今天及前29天，已有较早记录仍可编辑      |
| weather             | SUNNY / PARTLY_CLOUDY / CLOUDY / RAINY / STORMY / TYPHOON / CUSTOM |
| weatherName         | CUSTOM 必填1—20个Unicode码点的单行名称；普通天气必须省略           |
| tags                | 白名单8选、最多5个，可空                                           |
| text                | 最多1000 Unicode码点，可空                                         |
| expectedVersion     | 新建为0，修改使用刚读取的版本；删除后重建不复用旧记录版本          |

所有请求另带 apiVersion、requestId、action、payload。journal.get 输入 date；journal.delete 输入 date 和正安全整数 expectedVersion。客户端不得传 ownerId、openid 或角色。成功返回 entry 含 id/date/weather/tags/text/version/createdAt/updatedAt，CUSTOM 另含 weatherName；不包含内部归属字段。

错误码使用 INVALID_INPUT、CONFLICT、NOT_IMPLEMENTED、UNAUTHENTICATED、ACCOUNT_DISABLED；不存在 UNAUTHORIZED。结果未知或网络失败保留输入和原请求，不能按明确未写入处理。重试复用原 requestId 和原 payload；冲突不静默重读覆盖草稿，用户确认后再读取。

正式 journal/private review 仍未开放；显式服务器候选与内存演示各有本地证据，不能代替真实云端部署或手机验收。当前联调方法见 [W2 契约清单](../../week2/xiang-hong/contracts.md)；当前成员材料取舍见 [整合审查](../../reviews/2026-10-25-member-integration/pr51-review.md)。
