## 一、journal.upsert 输入

| 字段            | 类型       | 必填 | 说明                                                         |
| --------------- | ---------- | ---- | ------------------------------------------------------------ |
| date            | YYYY-MM-DD | 是   | 业务日期，服务端复核新建窗口（今天及前 29 天）               |
| weather         | enum       | 是   | SUNNY/PARTLY_CLOUDY/CLOUDY/RAINY/STORMY，扩类待 H02 接口评审 |
| tags            | string[]   | 否   | 白名单 8 选，最多 5 个                                       |
| text            | string     | 否   | ≤1000 码点（Array.from 计数）                                |
| expectedVersion | int        | 是   | 新建=0；编辑=读取到的当前版本                                |

## 二、返回与错误

- 成功：{ entry }（含自增 version、createdAt/updatedAt）
- INVALID_INPUT：字段不合法或超出新建窗口
- CONFLICT：expectedVersion 与当前版本不符；页面保留草稿与原请求，重新读取前需确认放弃输入
- NOT_IMPLEMENTED：正式云入口未就绪（当前状态，演示模式不受影响）
- UNAUTHORIZED：无有效身份（正式云启用后）

## 三、journal.get / journal.delete

| 接口           | 输入                   | 说明                                             |
| -------------- | ---------------------- | ------------------------------------------------ |
| journal.get    | date                   | 返回当天 entry 或 null                           |
| journal.delete | date + expectedVersion | 二次确认后提交；删除后同步刷新卡片并通知回顾刷新 |
