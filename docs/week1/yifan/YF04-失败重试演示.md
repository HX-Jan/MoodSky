## 演示点与验证结论

| #   | 要求                            | 实现与验证                                                                                                                                                                              |
| --- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 保存中禁止重复提交              | 保存请求发出后 inputLocked=true：天气格、标签、输入框、保存按钮全部禁用；按钮显示 loading。实测连续点击只发出一次请求                                                                   |
| 2   | 失败后保留输入                  | 演示按钮触发"保存后响应丢失"（NETWORK_ERROR）：已选天气、标签、正文原样保留，页面出现"重试原操作/重新读取"                                                                              |
| 3   | 重试复用原 requestId 和 payload | 点"重试原操作"：控制器保存原请求对象（requestId、payload 引用不变）直接重发；服务端按 requestId 命中已保存结果幂等返回，不生成第二条记录。验证：重试成功后当天仅一条记录、version 只 +1 |
| 4   | 成功后通知回顾刷新              | ✅ 已实现（W1 Z05 集成）——保存/删除后 reviewStore 发布失效事件，月历与卡片订阅重渲染；Today 页 onChanged → reviewStore.syncFromJournal（源码：pages/today/index.js）                    |
