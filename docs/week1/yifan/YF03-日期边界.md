## 一、日期规则（与代码 canCreateEntry / 页面提示一致）

| 规则                        | 结论                                                        |
| --------------------------- | ----------------------------------------------------------- |
| 新建（含补记）窗口          | 今天及此前 29 天，共 30 个自然日（2026-09-17 ~ 2026-10-16） |
| 30 天及以前（≤ 2026-09-16） | 不可新建；若该日已有记录，可打开编辑                        |
| 今天已有记录                | 不可重复新建（同日唯一）；显示已保存卡片，走编辑            |
| 编辑旧记录                  | 必须带 expectedVersion = 当前版本；版本不符返回 CONFLICT    |
| 日期导航                    | ‹ › 逐日切换，› 在未来日期置灰；日期选择器上限 = 今天       |
