| 场景             | 第二版的变化                                                           | 验证结果                                                                                 |
| ---------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 连续查看记录     | 增加“前一天、后一天、回到今天”；今天不能继续进入后一天                 | 模拟器实际点击通过，月份和闰日边界本地测试通过                                           |
| 草稿期间切换日期 | 确认前留在原日期，提示即将查看的目标日期；可保留输入或明确放弃         | 模拟器取消、确认、返回已保存日期均通过                                                   |
| 确认提示位置     | 切换日期的确认出现在日期按钮下方；同日重新读取仍在原表单操作区确认     | 已检查实际截图和提示文字                                                                 |
| 多日期内容       | 每次确认后读取目标日，避免把上一日草稿当作另一日记录                   | 两个日期的合成记录分别保存和读回通过                                                     |
| 读取状态         | 区分“正在读取、未读取、已有记录、尚未记录”；读取失败不显示确定的空记录 | 本地失败响应和延迟响应测试通过                                                           |

| 字数边界         | 保留上一版按 Unicode 码点限制的行为                                    | 模拟器输入 1000 个 emoji 可保存，1001 个不能保存且内容不截断；没有提交这两段长度测试内容 |
