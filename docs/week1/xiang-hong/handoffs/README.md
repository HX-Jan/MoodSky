## 使用方法

1. 将对应成员的独立 Word 文档转交本人，或让本人阅读本目录的文字版。每份包含已提供信息、具体样例、现有文件入口、使用步骤、需要交回的结果和限制。
2. 本包引用的既有文件链接可在仓库内打开，另有固定到 `a75e207` 的 GitHub 来源链接。成员在自己的仓库中使用路径时均相对 MoodSky 根目录。
3. 成员确认实际接口和前置输入，按文档准备本地交互、样例或测试；需要真实平台权限时把具体需求交负责人。管理员账号由本人登录，不转交密码或凭证。
4. 成果放本人 docs/week1 目录，回传任务编号、成果或 PR、实际版本和环境、预期/实际、证据、复核意见、实际耗时、后续估点和阻塞。没有实际反馈的接收/验收状态保持待复核。
5. 成员代码经 PR 审批后合入；负责人先处理成员 PR，再同步主分支并整合发布。共享接口、数据库和导航变更共同复核。
