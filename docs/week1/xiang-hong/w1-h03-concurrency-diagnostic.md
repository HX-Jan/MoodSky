## 1. 要解决的证据缺口

[上次真实实验](w1-h03-report-retention-validation.md)保存并取回了完整报告，12 项通过、5 项并发失败，失败安全码均为 -501001。[离线 SDK 分析](w1-h03-concurrency-analysis.md)证明多个后端原因都可能被转换为该数字，当前不能确认真实云端根因。

本候选增加定位证据，继续保留失败；没有把数字错误当作业务 CONFLICT、增加业务重试或放宽任何断言。原 17 项场景、固定合成时钟、重试配置、授权检查、集合与索引范围保持原样。

## 2. 两项实际改动

第一项是在 5 个并发场景中等待两路操作都结束，再执行原有断言或上报拒绝。两路全部成功时保持输入顺序；发生拒绝时保留汇总器最先观察到的原始错误，包括 null/undefined，不提前返回后把另一条仍在进行的操作归到下一项场景。等待不会发起新的写入或重试。原场景断言代码除调用等待函数外已逐字核对一致。

第二项是对失败结果增加可选 lastOperation 字段，仅保留以下 11 个固定标签：

| 标签                  | 含义                                                                 |
| --------------------- | -------------------------------------------------------------------- |
| input-validation      | 已进入输入校验                                                       |
| transaction           | 已进入事务调用或回调返回阶段；不能区分启动、提交、内部重试或回滚失败 |
| account-read          | 已进入账号读取                                                       |
| receipt-read          | 已进入回执读取                                                       |
| journal-read          | 已进入当日记录读取                                                   |
| account-fence         | 已进入账号竞争字段写入                                               |
| journal-write         | 已进入记录变更                                                       |
| deletion-marker-write | 已进入删除标记写入                                                   |
| revision-write        | 已进入来源/导出失效版本写入                                          |
| receipt-write         | 已进入回执写入                                                       |
| post-commit           | 事务调用已成功返回，进入合成响应丢失检查                             |

标签表示失败前最后进入的探针操作，不能证明错误就是在对应后端位置产生。它可能对应本地检查、SDK 回滚或内部重试之前的最后观测点，不表示该操作已提交。若错误来自夹具创建、独立查询或原场景断言，缺少观测就不填标签，不推测。

标签在每个实验 harness 的内存 WeakMap 中关联原错误，不修改、包装或记录原错误对象。若同一个错误对象被不同操作复用，出现矛盾标签后不再返回该标签。成功结果不附加标签；正文、身份、指纹、requestId、错误消息及堆栈均不进入新增诊断字段。

## 3. 报告兼容与边界

报告 schemaVersion 仍为 1；新增字段只允许出现在失败行，且必须是上表枚举。未知、过长、类型错误的标签或成功行附带标签会使报告被判为 invalid，不向外传原值。其他未知字段继续由原安全投影移除。

实际已保存的旧 17 项报告通过新版校验，读取不新增标签或改写结果；从未保存报告的旧批次继续返回 missing/null，不回填。报告仍与最终状态在原有同一次 update 中提交，没有增加数据库诊断写入或日志输出。

等待两路结束可能延后汇总；函数 60 秒运行限制保持原样。如果结束前被平台终止，报告仍可能缺失，不提供自动续跑或重发。candidate 也没有实现对精确后端符号码的恢复，因此本步通过不能写成 5 项云端失败已解决。
