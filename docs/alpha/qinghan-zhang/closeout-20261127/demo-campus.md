# 校园演示

使用同源码的隔离开发者工具项目。磁盘个人配置保持 `cloudEnabled: false`、
空 `cloudEnvId`、`journalDemo: false`。通过本机 9420 桥接和合成账号运行
`tools/alpha-qc/wechat.cjs --campus-task moodsky_01_walk`，
再另用一个空输出目录运行 `--campus-task moodsky_02_read`。
原样候选的云配置只作静态校验。

1. 在小任务页选择「去散散心」或「找个地方看会儿书」。
2. 进入校园后查看方位和到访提示，实点福友阁右侧「选这里」。
3. 查看暂停提示及禁用的「暂不可打卡」。独立离线服务探测展示拒绝回执。
4. 返回小任务页，确认原任务仍显示已选择。
5. 打开校园「我的打卡」，用独立可读历史夹具展示分页；避免把空历史解释成真实账号数据。

地点开放仍以现场公告为准。Junhan 核对接口和历史保留规则，Yuen 核对候选来源，
Jiaqi 和洪翔使用带来源的运行材料。
