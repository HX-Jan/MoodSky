## 实际现象

A 手机退出 MoodSky 后，再次点击微信一键登录，仍读取该手机当前登录的微信账号 A；小程序内不能选择第二个微信账号。A、B 虽分别在两台手机，但 B 的常规页面没有输入 A 记录标识、A 导出 `jobId` 或回执的入口。

因此，已有 A/B 页面只能说明客户端分别显示本人数据，不能证明 B 已向服务端请求 A 历史或 A 导出后被拒绝。

## 影响与边界

- 不将 B 的空页面、未登录状态或没有 A 内容写成 `FORBIDDEN`／`UNAUTHENTICATED`。
- 不将 GitHub 仓库 SHA 写成设备运行 SHA；设备实际构建与环境仍未确认。
- 这不是已确认的越权漏洞，也不是服务端已经拒绝越权的证据；它是 C1 测试能力不足导致的阻塞。
