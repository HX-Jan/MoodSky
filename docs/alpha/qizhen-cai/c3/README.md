## 边界与待验

1. 本轮是一次性内存库的生产入口复核，不能替代真实云端请求、真实设备构建、微信文件送达或维护环境清理回执。
2. `FORBIDDEN`、`CONFLICT`、`ACCOUNT_DISABLED` 均是本地合成夹具的实际响应，**不能写成**对用户真机 A/B 账户的真实云端回执。
3. 归档运行时没有远端 Git 工作树；本地快照 SHA 仅用于复现该次运行，不能替代 `origin/main` 或设备运行 SHA。
4. 真机导出只能预览而不能发送/保存、以及分享/服务日志缺失，仍按 C2 问题记录和 C1 阻塞项继续待验。
