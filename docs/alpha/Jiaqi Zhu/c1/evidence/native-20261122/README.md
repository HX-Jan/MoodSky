## 采集中的错误与复测说明

运行时注入本机账号夹具的几次尝试遇到原生方法或代理边界问题，失败记录保留，失败后核实云开关关闭、会话清空。没有把 Node 自测成功写成原生安装成功。后续若改用编译时平台适配，必须另列预览差异及实际结果。
