# 答辩演示分镜准备稿

编制于 2026-11-21，供 C3 编排、C4 同构建演练使用。已核对源码入口，GUI 尚未演练。参考本机源码 de71c844c40b481923e7d5e2e5120e0fd7da3a1e；演练前改记共同最终完整 SHA、预览配置、数据种子和图像哈希。页数和时长由班级实际通知与团队决定。

## 演示前准备

- 由洪翔明确演示范围，Yuen 核对独立禁云预览和所需本地桥接。普通记录演示可在独立副本使用 `cloudEnabled:false`、`journalDemo:true`；任务显式记录 `taskMode`。保存原配置并在结束后恢复。
- 日期使用演练当天的业务日或允许新建的近 30 天日期，只输入合成内容。分享、账号、导出使用专用合成身份和本地桥接；普通 demo 没有正式账号回执时，停在已支持入口并展示已执行报告。
- 原样候选只核对最终 `sourceCommit`、配置和哈希。演示预览的配置差异另记，候选端云、真实手机送达和平台审核按各自证据说明。

## 链路 A 记录 → 回顾

| 步骤 | 实际入口与动作                                                                                                                                    | 所需模式／数据                                          | 预期画面与观察                                                     | 重置及失败备用                                             |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------- |
| A1   | 底栏“今天”，`pages/today/index`；选一个普通天气，按保存                                                                                           | 禁云记录 demo，当前业务日无记录                         | 首页导航标题 MoodSky；天气必选、文字可空；区分演示保存与真实云回执 | 重置专用 demo 数据后再演练；读取失败时展示 C1 实际恢复报告 |
| A2   | A1 保存后点击“修改这条记录” → `pages/record/index?date=YYYY-MM-DD`；选择标签并写合成短文。尚未保存时入口为“添加标签或文字”，可附当前 weather 参数 | 同一 demo 会话；页面从 `onWrite` 取得合法日期及所选天气 | 私人范围、选填与未保存输入说明清楚；按钮有可辨反馈                 | 未确认保存时保留原输入并按原操作恢复，不切换请求补造成功   |
| A3   | 底栏“天气宇宙”，`pages/universe/index`；选同一月份并点有记录日期                                                                                  | 与 A1/A2 同一共享合成数据；等待实际月份读取结束         | 保存记录出现在对应日期；空日期保持未记录                           | 若未同步先记录构建、原步骤和实测；回顾断网用已执行报告备用 |
| A4   | 由月历打开 `pages/review/detail/index`，或“月份档案” → `pages/review/archive/index?month=YYYY-MM`；“天气回顾” → `pages/review/insights/index`     | 详情参数使用页面生成的本人记录 ID；与种子预期核对       | 月历、详情、档案、回顾描述同一组记录；私人正文按实际展示规则处理   | 对照模块种子预期，缺少当前运行图时使用报告并标明来源层级   |

入口依据为 `pages/today/index.js` 的 `onWrite`、`onEditEntry`，以及 `pages/universe/index.js` 的日期点击、`onOpenArchive`、`onOpenInsights`。

## 链路 B 小任务 → 校园 → 返回

| 步骤 | 实际入口与动作                                                                                         | 所需模式／数据                                                                                            | 预期画面与观察                                                         | 重置及失败备用                                                       |
| ---- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------- |
| B1   | 底栏“小任务”，`pages/tasks/index`；按当期允许模式进入可操作的合成状态                                  | 必须明确 `taskMode:enabled`；普通 demo 需点击“进入本地登录演示”，或由已准备的本地生产入口桥接提供合成会话 | 三模式提示正确；选择按钮在卡片右侧，忙碌、只读或关闭时无误导操作       | `closed` 只演示未开放；`readOnly` 只演示浏览。两者均停止在其实际边界 |
| B2   | 选择 `destination:campus` 的合成任务，或由已选任务“选校园地点”入口进入 `pages/campus/index?fromTask=1` | 模块主责确认任务模板与回执；等待选择结果确认                                                              | 校园显示当前推荐，卡片右侧“选这里”；选择地点不自动完成任务             | 选择结果未知时留在原页，用原请求重试；以实际异常报告作备用           |
| B3   | 校园中点击一个地点的“选这里”，再按页面实际状态操作                                                     | 固定五地点合成状态；新增打卡暂停时保留暂停配置                                                            | 地点选择与完成分开。暂停状态明确说明下一步，不能演成成功到场或完成打卡 | 暂停时停在暂停提示；不绕开开关生成成功图                             |
| B4   | 原生返回小任务；观察状态后，再显式“完成”                                                               | 与 B2 相同任务，服务允许该动作                                                                            | 返回后仍为已选择；只有匹配回执确认显式完成才显示已完成                 | 核对失败／未知状态与重试路径；结束后重置本地任务副本                 |

入口依据为 `pages/tasks/index.js` 的 `onOpenActivity`、`_openActivityFor`，以及 `pages/campus/index.js` 的 `onChooseTaskPlace`、`onCheckinTap`。C1 发现的四个任务按钮动效禁用条件异常，已在本地提交 b289239d41aae645e7e8ea41ff0122de5fa78610 修复。演练前核对共同版本是否采用，再在相同条件下复测。

| ---- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
