## 本地接入与验证

现有 `createWeek2Backend` 新增显式 `memberServices: {store, taskStore, env, receiptSecret}`。统一账号 repository 由工厂构建，不由客户端传入；候选时钟沿用 now。store 必须绑定同一账号数据源，taskStore 必须显式提供；不静默补内存模型或自动连接云库。未传 memberServices 的既有行为不变。公共任务目录仍由 taskSuggestionsEnabled 单独控制，当前页面继续只读，不把服务器候选等同于前端正式接入。

新增四个联合用例验证：真实候选账号首建→私人偏好→CUSTOM 记录→月份回顾与双账号隔离；游客有界只读建议→私人任务幂等/历史 schema；同一账号停用后记录/任务拒绝；更新 0 行不能报告成功。数据库均为本地替身，任务 store 为内存，真实账号和网络未使用。测试数据库替身增加实际字段投影支持，未把生产错误伪造为成功。

完整 `cloud:prepare + check`：lint、格式、结构、类型检查及 **681 项测试全部通过**；原 593 项回归保留，成员 84 项与联合新增 4 项分别标明。正式入口和默认域与基线相同，无新云写入、部署、密钥配置或微信包上传。
