# 成员 PR 整合核对表

每个 PR 复制以下表格填写在其审查记录中，PR 模板链接到该记录。选择当前需求和已验证行为最合适的组合，不按作者或提交时间整包覆盖。自动文件比较用于发现差异，人工取舍与实际路径验证仍然必须执行。

## 固定来源

| 项目            | 待填写内容                              |
| --------------- | --------------------------------------- |
| 成员、PR 与职责 | 作者、PR 链接、涉及模块                 |
| 原始交审提交    | 完整 SHA；不是只填整合修改后的最终 head |
| 审查期间新提交  | SHA、追加内容；发布前再次读取           |
| 主分支基线      | 完整 SHA                                |
| 本次整合结果    | 分支、提交；未提交时明确工作区版本      |

## 逐项取舍与接线

| 原交付项/源文件        | 现有重叠实现/原设计                  | 采用的组合与理由                            | 实际入口/调用方                   | 验证与证据                          | 暂缓部分及责任人                     |
| ---------------------- | ------------------------------------ | ------------------------------------------- | --------------------------------- | ----------------------------------- | ------------------------------------ |
| 示例：天气选择与私人页 | 设计布局、既有版本与原请求重试控制器 | 原设计布局 + 已验证控制器；新增枚举另行定案 | Today → 私人页 → 保存/取消 → 回顾 | 原图/实际截图；保存、取消、失败重试 | 自定义字段需设计/前后端/数据共同确认 |

## 完成核对

- [ ] 已列出原始、最终 PR 与目标分支的全部文件差异，逐项解释删除、替代、移动和新增内容。
- [ ] 已核对素材、文档、测试和实现；已关闭未合并的 PR 也说明是否吸收、空交付或仍欠修改。
- [ ] 已运行关键实际入口；原设计与实际截图有并排或可切换对照。
- [ ] 旧功能在新界面仍可进入；成功、失败、取消、回退和隐私门禁有对应证据。
- [ ] 已同步成果索引和任务台账，保留原始证据，不代签独立验收。
- [ ] 已说明真实业务、模拟器、云与真机的边界；部署请求单独处理。
- [ ] 发布前重读成员 PR 最新 head 和未解决讨论，再按既有拥有者审批及 quality 规则合入。

不要因为表格勾选或 CI 成功自动批准 PR。视觉采用应由原稿和实际页面判断；契约冲突按共享文件责任人协作定案。
