# 微信登录与个人中心样式调整

2026-11-01，负责人认为账号展示不美观，要求采用日常小程序常见的微信登录形式。本次从c25f0fa继续，重做生产配置下的个人中心、登录页和资料表单，保持现有微信身份登录与私人资料服务。

## 页面与入口

“我的”使用头像、昵称和分组列表。未登录显示“点击登录”，整个头像区域可进入微信登录；登录后显示本人已设置的头像昵称，点击同一区域进入个人资料。未设置昵称显示“微信用户”。默认头像使用统一的浅绿色人像占位，已设置头像使用原图裁切展示。长昵称省略显示，保留单行布局。

首页移除重复的登录/编辑按钮、大标题和大段说明；记录、账号数据、分享、帮助、反馈、隐私和更新改为列表菜单，帮助与数据说明按需展开。“我的天气记录”和“账号与数据”在访客状态先登录，再回到对应入口。

登录页使用白底、应用图标、微信绿色“微信一键登录”按钮、明确的隐私勾选和“先逛逛”。勾选仍由本人操作，保留微信隐私授权及可信云身份握手，不添加手机号或密码步骤。

个人资料使用常见的头像行、昵称行和保存按钮。头像仍为chooseAvatar，昵称仍为type=nickname并通过form提交经微信检查的值。两项都可选，不把静态示例当作微信自动返回的个人资料。昵称blur也标记编辑状态，避免微信原生填写后遗漏更新保护。
