# 微信登录页与个人资料

2026-11-01，负责人进一步选择“点击微信登录，进入本人账号，可设置头像昵称”。本次在019e506微信身份按钮和分享实现上补齐完整用户流程，替代此前个人中心的重新验证按钮。

## 使用流程

未登录时可浏览校园等公开内容；记录入口显示微信登录引导。进入独立登录页，阅读隐私保护指引并勾选同意后，点击“微信一键登录”；若微信要求隐私授权，由微信原生流程处理。成功后进入“我的”，显示本人账号及个人资料入口。

头像昵称均可选填，使用chooseAvatar和nickname输入组件。昵称通过表单提交收集，最多20个Unicode码点；头像在本机压缩到128像素，最多32KiB，仅接受PNG/JPEG图片内容。未填写时使用默认头像和“天气记录者”。原生组件的微信头像选择、昵称建议和安全检查最终须在真实手机验证，不能用模拟器替代。

本地只保存“曾主动登录”的布尔流程标记，不保存微信code、session_key或账号凭据。重新打开时仍通过可信微信身份向现有account.session验证。退出登录会清除标记和私人显示，不删除云端账号；注销沿用既有停用与清理流程。

当前使用微信云开发已有的可信调用身份建立服务会话，不额外调用wx.login后丢弃其code，不引入客户端AppSecret，不依赖已弃用的自动头像昵称获取方式。

## 服务与数据

新增私有account.profile：get读取本人资料；set提交nickname、avatarData和expectedVersion，服务器仍以本次调用的微信身份及scope确定账号。保存使用现有事务围栏、来源修订和导出失效协议，原requestId重试不重复推进版本，旧版本不覆盖新资料。

资料存于现有preferences文档的profile字段，不增加集合、索引或客户端数据库权限。JSON/Markdown导出包括本人头像昵称，屏蔽请求ID与摘要等内部字段；资料变化会使旧导出失效。已上线维护程序本来就清除preferences，因此不需要改动或重新部署定时维护函数。

部署范围仅为moodsky-release的index.js增量更新。现有稳定身份、会话及回执密钥、runtime.local.json、依赖、超时、定时器和数据库权限沿用。新API对已有客户端保持兼容；尚未完成实际部署时，不能把新资料保存说成线上已可用。

20项新增资料与登录流程检查覆盖原生数据库SDK离线序列化、真实处理器下的合成双身份隔离、资料持久化及重试、导出与注销清理、非法图片与伪造归属、协议拒绝、登录恢复和资料迟到响应。连同既有检查，完整check共1066项全部通过，无失败、跳过或取消。

登录页与资料页WXML通过微信开发者工具编译。实际模拟器显示登录页及默认未连接资料状态；切页后自动化连接出现过timeout与No context found，保留该限制。资料编辑布局另外用隔离的合成渲染页检查，该页不进入生产包，也不作为真实云端保存证据。

## 手机验收

1. 首次进入记录入口时可前往登录，也可先浏览公开内容；未同意时不开始登录。
2. 同意指引后点击微信一键登录，进入“我的”；关闭后重开，验证仍为本人账号且原记录保留。
3. 打开“设置头像与昵称”，选择头像、填写昵称并保存；退出资料页再进入或重开后仍能读取。
4. 取消头像选择、取消登录、网络失败及重试均不显示虚假成功；退出登录后不显示旧头像昵称。
5. 本人导出包括主动设置的资料；真实注销会停止访问并清理资料，仅在实际需要时操作，不为演示重复注销账号。
6. 分享卡片仍为固定首页和静态图标，不带头像、昵称或日记；由另一位真实用户验证独立账号。

发布前按实际功能核对微信后台隐私保护指引中的头像昵称用途；本次没有通过浏览器修改微信公众平台配置。

- [隐私授权辅助接口](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/privacy/wx.requirePrivacyAuthorize.html)：已同意或拒绝时的原生回调。
