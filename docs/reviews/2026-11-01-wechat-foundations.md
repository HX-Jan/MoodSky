# 微信日常使用基础功能

2026-11-01，在182260e的微信登录、资料和当前页分享基础上，负责人要求继续补齐微信小程序的基础体验。本次只修改客户端，不开放新的业务权限或部署云函数。

## 已接入的行为

- 全部13个正常页面展示断网提示，恢复网络后提示手动重试；不会自动重发保存、删除、资料、导出或注销请求。初始网络查询的迟到结果不能覆盖之后的网络变化；回到前台重新查询网络。
- 使用微信UpdateManager接收检查、下载完成和失败状态。微信在启动时自动检查更新，“我的→版本与更新”展示该次状态，不伪造主动检查接口。下载完成后提示用户更新，只有用户确认才调用applyUpdate；草稿、进行中的操作及结果未确认的原请求会阻止重启，确认弹窗返回后再次核对。页面组件登记仍存活的页面，以保护不在当前路由栈中的缓存Tab草稿；组件销毁时解除登记和订阅。
- 分享进入的非Tab根页面提供“回到首页”。未保存修改先确认放弃，操作进行中或结果未确认时保留页面。记录删除成功后的返回和详情返回增加首页兜底；不存在的页面回到首页。
- 正式配置的“我的”提供可展开的常见问题、微信原生隐私保护指引、原生意见反馈、版本与更新。访客也可使用这些帮助入口。版本展示优先使用微信包版本和开发/体验/正式环境信息，不能把本地候选包当作已发布新版。
- 头像和昵称修改纳入草稿检测。头像昵称保存仍使用原请求重试、版本校验及私人账号隔离。
- 朋友圈单页模式继续只展示静态介绍，不挂载上述组件，不启动网络监听、更新管理或云服务。从该模式进入正常小程序时，正常生命周期可初始化服务。

## 手机核验路径

1. 在新预览的“我的”打开使用帮助、隐私指引、意见反馈及版本与更新；反馈内容由本人决定是否提交。
2. 在页面断网再恢复，核对提示变化；未确认写入仍需重试原操作，不能凭网络恢复提示判断已保存。
3. 从好友分享进入记录或回顾根页面，检查回到首页、取消放弃修改、删除后的返回。
4. 后续正式新版下载就绪时，先保留一处未保存草稿，检查更新被阻止；保存或明确放弃后，确认更新才能重启。

## 官方依据

- [UpdateManager.onCheckForUpdate](https://developers.weixin.qq.com/miniprogram/dev/api/base/update/UpdateManager.onCheckForUpdate.html)：微信每次启动，包括热启动，自动检查更新。
- [UpdateManager.applyUpdate](https://developers.weixin.qq.com/miniprogram/dev/api/base/update/UpdateManager.applyUpdate.html)：下载完成后调用，强制重启并应用新版。
- [网络状态变化](https://developers.weixin.qq.com/miniprogram/dev/api/device/network/wx.onNetworkStatusChange.html)：读取isConnected和networkType。
- [原生button开放能力](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)：feedback打开微信意见反馈页面。
