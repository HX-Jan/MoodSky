# 手机号快捷登录与注册候选

2026-11-26。基于主干 `3dd813d63123c8dbf74a2a2e42542b354b77dbb1`，采用蔡奇真 PR #237 当前交审 `1eab5739eef3bcb0b2959d1afdce39c4fbdbe992` 的净增量，再完善首次注册、旧账号关联、注销后空账号重注册和登录界面。没有用旧分支整包替换主干。客户端和服务端默认关闭；源码及本地候选不代表部署或平台声明生效。

## 页面与操作

1. 展示天气标识、用途说明、未预选的隐私同意框。功能开放后，「手机号快捷登录」为主按钮，「使用微信登录」和「暂不登录，先看看」保留入口。未勾选同意不会触发手机号授权。
2. 勾选后触发微信原生 `getPhoneNumber` 弹层。用户主动选择和授权号码，不能静默读取 SIM 卡。页面不伪造手机号或短信弹层，不自行发送短信。
3. 新用户授权未注册号码后直接建立空账号并登录，不要求预先微信登录。已有号码返回同一有效账号；界面仅显示掩码号码。
4. 当前微信有未关联号码的旧账号时，询问「关联现有记录」。确认后关联并保留旧记录；取消不改变数据。确认复用服务端短时票据，不要求第二次授权，不重复消费原 code。
5. 号码对应账号已注销时，询问「重新注册」，明确旧记录和导出不会恢复。确认后创建新一代空账号，旧账号的清理继续执行，不影响新账号。仅重新授权不会自动复活账号。
6. 退出后可再次通过原生弹层选择号码；不同号码对应独立账号。已有号码可在另一微信中重新验证登录，凭证绑定此次实际微信身份。微信登录入口不会自动合并账号。
7. 取消、隐私限制、权限、额度、网络及未返回授权码分别反馈。失败不建立会话，微信登录和公开浏览仍可用。离页、切号或撤回勾选后，尚未发送的确认中止，迟到结果不能建立或切换本机会话；已明确确认并发送的请求可能已在服务端完成，不能把取消界面当作回滚，重新授权后以服务端状态为准。

当前只支持中国大陆号码，不支持直接换绑或合并两个已有账号。原微信登录和确认后空账号重注册保留。手机号主账号与未关联的微信账号可能不同，不能按同一微信推断私人数据相同。

## 接口与身份

| 操作                   | `account.phoneLogin` 输入                                 | 成功结果                 |
| ---------------------- | --------------------------------------------------------- | ------------------------ |
| 登录或首次注册         | `{mode: 'login', code}`                                   | 已认证会话，或待确认结果 |
| 已登录微信账号主动绑定 | `{mode: 'bind', code}`，同时验证可信微信和 `sessionScope` | 关联原账号，不抢占号码   |
| 确认关联旧记录         | `{mode: 'link', ticket, confirm: 'LINK'}`                 | 原账号会话               |
| 确认注销后注册         | `{mode: 'register', ticket, confirm: 'REGISTER'}`         | 新空账号会话             |

待确认结果含 `authenticated: false`、`nextStep: 'link' | 'register'`、`phoneTicket` 和 `phoneLabel`，不能当作已登录。票据最长五分钟，签名绑定可信微信、号码摘要、前代账号、操作目的及期限。事务再次检查归属及生命周期；同次确认丢回执后重放不会新建第二个账号，旧确认不能重置后续一代账号。

前端只传一次性 code，服务端调用 `cloud.openapi.phonenumber.getPhoneNumber` 验证，不接受前端手机号、OpenID 或 ownerId 作为身份。code 结果未知时重新授权，禁止自动反复消费。首次注册及映射在同一事务中收敛。

号码用身份密钥 HMAC 摘要，在禁止客户端读写的 `accounts` 集合保存 `phone_<摘要>` 索引，类型 `verified-phone-index-v1`、状态 `mapping`。实际账号继续使用 `acct_` 身份和 active/disabled 生命周期；索引不是登录账号，不能按文档数推断人数。

已认证结果含原会话字段、最长七天签名 `phoneSession` 和掩码 `phoneLabel`。凭证绑定可信微信与账号，每个私人请求仍检查状态、范围和写入围栏。请求首次发送时固定凭证与范围，重试不能改用新账号。切号沿用会话代次、缓存及迟到响应隔离；退出清除本地凭证及标签。本地退出不等于撤销已复制的有效凭证。

## 信息影响与生命周期

| 项目           | 处理方式                                                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用途           | 主动手机号登录或绑定，仅用于身份验证、去重和关联，不用于营销或分析                                                                                                    |
| 流向           | 微信手机号服务到业务云函数内存；无新增短信 SDK，不向手机号服务发送日记                                                                                                |
| 服务端保存     | 号码带密钥摘要、账号归属及账号侧绑定摘要；不保存明文手机号、掩码号码或授权 code，不记录这些信息到日志                                                                 |
| 客户端保存     | 最长七天签名凭证内含掩码标签，仅辨识当前账号；短时确认票据仅在当前流程内存使用                                                                                        |
| 拒绝与撤回     | 未同意不触发组件；取消不提交确认。微信登录和公开浏览可用，退出清除凭证，注销停止私人访问                                                                              |
| 注销与重注册   | 旧私人数据进既有清理队列；映射指向确认后的新空账号，保留最近前代 ownerId 处理丢回执；旧记录、导出及偏好不恢复                                                         |
| 最小身份索引   | 注销后保留最小摘要及生命周期墓碑以防旧凭证/回执复活数据；尚无自动删除身份索引或自助换绑，正式隐私指引须明确并评审保留期限及解除方式，不能声称注销立即删除所有身份关联 |
| 导出与其他缺口 | 不将原始号码加入业务导出；现有 UGC 和真实生命周期补验单独跟踪                                                                                                         |

## 开启与发布

1. 2026-11-26 负责人已明确回传「收集手机号，用于登录和账号关联」的隐私声明已补充并生效；这是负责人确认，本轮未独立读取后台。PR #237 的 errno 112 为补充前原作者手机反馈，不能代表补充后的结果。接下来核对手机号能力、额度及配套包，真实授权重测通过才记为可用，不再将声明待补列为当前缺件。
2. 官方入口：[手机号组件](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)、[服务端接口](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-info/phone-number/getPhoneNumber.html)。本次工具未能读取这两页，资格和限制以当前后台核对为准。已阅读的腾讯云[微信小程序登录 API 模式说明](https://cloud.tencent.com/document/product/1441/68677)区分微信身份 code 与手机号 code，作为流程参考；本项目没有接入其 OneID 产品。
3. 最终干净提交先运行 `npm.cmd run cloud:prepare` 与 `npm.cmd run check`，再在源码目录用打包器显式启用候选。输出必须为工作区外全新绝对路径：

   ```powershell
   node -e "const p=require('./scripts/package-production'); console.log(JSON.stringify(p.buildProduction({outputRoot:process.argv[1],phoneLoginEnabled:true,requireClean:true}).manifest,null,2))" "C:\MoodSky-candidates\phone-login-candidate"
   ```

   普通 `release:package` 默认仍关闭手机号。显式选项同步生成客户端开关与业务云 `config.json` 的 `phonenumber.getPhoneNumber` OpenAPI 权限并纳入哈希，不能只改客户端。

4. 平台声明生效后，在配套业务云设置 `MOODSKY_PHONE_LOGIN_ENABLED=true`，保留三把不同的服务端密钥，身份密钥不能随意轮换。若采用既有服务器部署文件，手机号开关也可明确记录于该文件；平台未设置该开关时保留文件值，显式 `false` 或无效值关闭。平台完整密钥配置与文件密钥不混用。维护云不需要手机号权限。包内 `server.env.example` 是默认关闭的空密钥模板。
5. 部署、上传、真实授权和发布分别遵循用户授权范围。关闭服务端开关拒绝手机号登录及旧号码凭证，原微信登录仍可用；正式开放前完成真机验收。

部署后先核对业务函数 `system.health` 的完整 `buildCommit`、`configured:true` 和 `phoneLoginEnabled:true`；若字段缺失，不能视为本次配套后端。该布尔值仅反映服务器配置，仍需真机原生授权判断实际能力。源码、打包后的 SDK 入口和登录会话完整链路适配见[适配补充](reviews/2026-11-26-phone-adaptation.md)。

## 验证与待验

本地用合成号码、内存数据库和 SDK 替身，不调用真实手机号服务。覆盖默认关闭、新号码注册、同号收敛、异号日记隔离、旧记录确认关联、一次 code 后确认、取消/离页、票据篡改/换微信/过期/用途不匹配、并发确认去重、注销后空账号重注册、旧清理不删除新账号及 B 数据、凭证恢复/退出与标签清理。

模拟器视觉编译、后台声明、真机授权及真实云维护分别登记，不得将未执行项目填通过。真机至少验证原生选号码/其他号码、拒绝与失败分类、新旧用户登录、旧账号关联、A/B 日记隔离、退出重开、断网丢回执、离页迟到响应、注销和空账号重注册，以及真实维护后旧导出受限且新数据完整。记录客户端、业务云与维护云实际构建；证据不上传真实号码、code、票据和凭证。
