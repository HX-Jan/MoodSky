# 微信登录、当前页分享和个人中心更新

2026-11-01，负责人要求将这轮已完成的功能上传GitHub并更新main。此页描述最新源码及其既有部署/预览证据；微信正式上线版本仍为0.3.0，本轮源码整合不上传微信代码或发布公开客户端。

## 功能

- “我的”顶部为头像昵称区域。访客点击进入微信一键登录；登录后点击编辑个人资料。头像和昵称可选填，使用微信chooseAvatar及type=nickname表单；昵称未设置时显示“微信用户”。
- 资料保存采用私人account.profile接口，保留版本围栏、原请求重试和跨账号清空；JSON/Markdown导出包含本人设置的资料，注销沿用既有清理协议。
- 全部13页适配右上角“…”好友与朋友圈分享，目的页恢复合法日期、月份、统计天数或任务视图。链接和卡片不携带正文、头像昵称、账号、记录ID或回执；接收者使用自己的微信账号。未登录的私人页面先登录再回原入口。
- 朋友圈单页场景1154展示静态功能介绍，跳过私人业务、网络监听及更新管理；正常小程序中继续使用原生分享菜单。
- 分组菜单、隐私指引、原生意见反馈、使用帮助、断网恢复提示、版本更新提示与未保存操作保护已接入。网络恢复不自动重发写入，新版下载就绪后由本人确认重启。
