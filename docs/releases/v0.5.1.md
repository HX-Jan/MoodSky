# MoodSky v0.5.1

- 小任务从底栏进入。「去散散心」「找个地方看会儿书」打开校园地点，从「记录一下心情」进入私人记录，保存后返回小任务。已有云端启用模板优先，目录为空时提供内置活动。
- 校园支持先选地点、到达后手动完成。已下架地点保留在本人历史中，新增打卡仍限当前推荐地点。[Junhan Huang 的修复与本地验证](https://github.com/HX-Jan/MoodSky/pull/177)
- 导出按申请时选择的 JSON 或 Markdown 格式领取。电脑微信可保存到磁盘，手机微信可发送到聊天。原格式交付失败时可主动领取同内容的兼容文本。[导出修复](https://github.com/HX-Jan/MoodSky/pull/179)
- 归档蔡奇真的现场验收报告。旧测试包申请导出后保存失败，账号注销进入停用和清理中。新版的实际文件交付仍待设备复验。[W5-C 现场记录](https://github.com/HX-Jan/MoodSky/pull/178)

## 构建和联调

在仓库根目录运行 `npm ci`、`npm run cloud:prepare`、`npm run check`。运行 `npm run release:package -- <新绝对路径> enabled` 生成联调包。导入包根目录下的 `project.config.json`，在 `manifest.json` 核对来源提交与文件指纹。

本版本的 GitHub Release 提供源码和联调包。微信体验版更新、配套云函数部署和新包的真机验收待执行。使用同一包的维护与业务函数，先准备维护函数，再更新业务函数并保持新增打卡暂停。用授权测试账号复验本人历史、导出、账号隔离及注销清理，确认后再开放新增打卡。校园不需要定位权限。
