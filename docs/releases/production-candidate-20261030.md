## 已完成的代码行为

- 使用本次微信调用的可信身份核对AppID、环境和来源；忽略客户端伪造身份。身份转换成服务器HMAC映射，确定性账号文档通过事务完成首建，已有停用账号不复活。没有把微信原始OPENID写到新账号行。
- 记录、修改、删除和回顾接通现有确定性日记存储；保留版本冲突、原请求重试、来源版本和跨账号响应隔离。客户端关闭后从服务器重新读取，演示配置不会自动回退。
- 私人任务使用现有事务存储；新写入同步推进对应来源版本，旧导出随源数据变化失效。公开任务可为空，不注入合成资料。
- 导出提供JSON和Markdown，领取前再次核对本人、账号状态、来源版本和24小时有效期。正文存于禁止客户端直读的任务行中，经已鉴权函数返回，没有公开存储地址。每个来源最多2000行、总文件最多512 KiB；超限明确失败，不返回截断文件。
- 注销将停用和清理任务写入同一事务，立即拒绝后续私人操作；网络结果不明时恢复同一账号任务。短期进度回执到期后，仅原微信身份和原账号绑定可以重新取得。
- 清理按每次最多10行、一个集合推进；文档删除与进度计数一起提交，失败可恢复，覆盖日记代际、偏好、任务、导出、删除账本及本人纠错资料，不删别人的记录或公共模板。完成后保留最小停用标记，防止旧备份或再次登录恢复访问。
- 独立维护函数扫描未完成清理任务，并移除过期导出正文；需要服务器专用触发令牌。微信客户端和伪造令牌不能触发维护。
- “我的”页接入真实数据页面，提供导出、注销、原操作重试和清理查询。关闭合成账号切换、假注销和演示成功提示。校园首发仅公开资料读取；未完成围栏接入的收藏、纠错、定位及装饰入口隐藏。正文卡片预览保持关闭。

## 配置与打包

AppID `wxf602e991ff44e6c8`，环境 `mood-sky-d5gqy3spkff37566d`。没有自建HTTP接口，候选使用既有微信云开发，不凭空填写服务器域名或购买资源。

在候选源码根目录执行：

```powershell
npm ci
npm run setup
npm ci --prefix cloudfunctions/moodsky
npm run check
node scripts/package-production.js 'C:/绝对路径/全新输出目录'
```

新页面必须已纳入Git，输出目录必须位于源码之外且不存在。打包复制跟踪的客户端文件，单独生成云端模式配置，移除发布包的定位权限声明，保留合法域名校验，不包含开发者个人配置或服务器密钥。manifest记录源提交、工作区状态和逐文件SHA-256。微信开发者工具应导入整个候选输出根目录：根配置指向client/miniprogram和cloud。模拟器检查发现工具会把越出项目根的云函数路径规范化，已据此修正打包布局，避免导入后找不到函数。

服务端需要三个独立32字节随机密钥的64位小写十六进制编码：`MOODSKY_IDENTITY_KEY_HEX`、`MOODSKY_SESSION_KEY_HEX`、`MOODSKY_RECEIPT_KEY_HEX`。仅在服务器环境设置；缺失、重复或未明确开启 `MOODSKY_PRODUCTION_ENABLED=true` 时业务保持关闭。示例文件故意留空，不生成或上传真实密钥。身份映射密钥必须稳定并安全备份，不能每次构建重新生成；轮换需要专门迁移方案。

所有业务集合继续禁止客户端直读直写。首次上线不迁移或覆盖原受限测试账号；它们的身份命名空间与正式账号不同。现有声明索引不代表平台已应用，需要平台核对。候选未新增集合，查询仍可能需要ownerId/_id、task_history日期和时间、cleanup_jobs状态、export_jobs状态/到期时间等索引。

2. 另存云端现有函数备份，核实运行时与当前SDK支持情况；先部署关闭开关的候选并下载比对文件，再配置服务器密钥和禁止客户端读取的数据库规则，随后做受控验证。没有执行这些操作就不能开放业务。
3. 部署 `moodsky-cleanup-worker` 并配置定时触发及服务器专用令牌；在真实环境确认清理继续执行和导出到期正文移除。触发令牌根据receiptKey对固定维护上下文计算，不写入客户端、仓库或日志。缺少定时触发不能声称离开页面后仍会自动完成清理。
4. 使用至少两个真实微信账号验证A/B隔离、重启读取、断网原请求重试、导出后修改失效、注销和清理恢复；取回服务端结果后再上传体验版并手机验收。独立验收由实际操作者回传。
5. 上述条件满足后再提交代码审核和发布。`0.3.0-rc1`是本地候选编号，不表示审核通过或现有体验版已更新。

## 验证边界与已知限制

本轮自动测试使用合成数据库、已安装的真实SDK及替换传输；没有真实私人数据，也没有访问生产数据库。首轮完整检查1022项通过；新增SDK并发首登检查发现会话读取不必要地写围栏导致争用，已改为只读事务；另一处SDK离线替身把导出的任务扫描错分到历史查询，已按实际查询形状分支，保留原断言。最终完整检查1025项通过，失败0、跳过0；其中本轮正式候选专项22项。新增账号页WXML/WXSS原生编译通过，9项实际微信模拟器检查通过，8次合成传输、真实云业务调用0次；测试后接口恢复且测试配置重新关闭云能力。模拟器首次连接超时、测试驱动的多行参数和方法绑定问题有原始日志，修正驱动后复测通过。最终结果见外层交付说明与测试日志。

云函数依赖直接固定 `@cloudbase/node-sdk@3.17.2`，更新qs锁定版本后依赖审计为0问题。原基础入口的“不开放私人业务”检查继续保留。

候选尚未经真实云端、手机和独立上线验收；并发离线模型不证明厂商实际隔离级别。维护任务是有界扫描，大量数据需要多次触发；畸形任务会报告重试，需要运营排查。导出超过限制时当前仅明确报错，分卷导出未实现。回顾卡片正文预览、正式装饰、校园私有维护和Web后台不属于这次首发开放范围。

微信公众平台自动访问被站点安全策略拒绝，本轮未改用其他入口绕过；本地候选准备与模拟器检查单独记录。
