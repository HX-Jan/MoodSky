## 制品与配置

从干净的最终 main 执行 `npm run cloud:prepare`、`npm run check`、`npm run team:check:production`、`npm run team:check` 和 `git diff --check`。再执行：

```sh
npm run release:package -- <工作区外的新绝对目录> enabled
```

以 `manifest.json` 中完整 `sourceCommit`、`sourceWorktreeDirty=false`、三处版本及客户端和两支云包的哈希作为同包依据。普通小任务沿用 `enabled`；校园新增打卡默认暂停，历史读取保留。包指向 `mood-sky-d5gqy3spkff37566d` 的 `moodsky-release` 与 `moodsky-release-maintenance`，不含服务器密钥、源工作区个人配置、定位能力或运营后台。

用微信开发者工具导入**制品根目录**，不要导入历史 MoodSky 目录或单独的 client 子目录。上传版本 `0.5.3`；备注写完整构建号及启用范围。版本相同仍须核对构建，不能凭数字跳过源码或云端差异。
