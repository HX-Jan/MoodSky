## 下载与构建

从 [GitHub 发行页](https://github.com/HX-Jan/MoodSky/releases/tag/v0.5.2) 下载联调 ZIP 和 SHA-256 文件。联调沿用 `taskMode=enabled`，校园新增打卡默认暂停。需生成任务关闭的候选时，从同一源码使用 `closed` 装配。

在干净的目标提交中先运行 `npm ci`、`npm run cloud:prepare` 和 `npm run check`。执行 `npm run release:package -- <工作区外的新绝对路径> enabled` 生成制品，核对 `manifest.json` 中的完整 `sourceCommit`、客户端及两支云包文件指纹。

此发行范围为 GitHub 源码及本地联调制品，目标云部署、微信上传、真实设备和正式提审留待同包验证及发布人确认。
