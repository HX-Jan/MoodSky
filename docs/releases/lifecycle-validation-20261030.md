# 0.3.0独立账号生命周期验证

2026-10-30，Asia/Shanghai。使用同一真实微信身份和字节相同的正式业务代码，在独立函数`moodsky-release-qa`配置三项独立服务器密钥，形成单独的账号映射、会话范围和清理回执。正式客户端仍只调用`moodsky-release`，没有重新上传客户端或注销正式账号。

## 真实验证结果

- 正式与测试空间的会话范围不同，跨空间会话访问返回UNAUTHENTICATED。
- 测试空间创建一条CUSTOM合成记录，申请并领取包含该正文的JSON导出，随后仅注销该测试账号。
- 注销返回disabled及清理回执；私人读取、旧导出领取和重新登录均返回ACCOUNT_DISABLED。
- 正式空间仍可认证，前后会话范围一致；测试空间清理回执不能用于正式空间，返回FORBIDDEN。
- 后台按批次自动删除1条记录、1条请求回执和1个导出任务，20:02:03完成清理。完成前没有调用会推进清理的cleanupStatus，观察过程仅通过只读、精确到测试账号的查询取证。
- 完成后对该测试账号的journals、request_receipts、export_jobs分别查询，残留均为0；凭回执查询完成状态正常。
- accounts中仅保留`_id`、`openid`、`identityKind`、`status`、`journalLayout`、`closedAt`六个字段；openid值为测试空间的不可直接识别账号标记，status为disabled，旧sourceRevisions已移除。没有把这些字段值放入公开证据。

为缩短验证等待，临时将同名维护触发器改为每分钟。19:59删除记录、20:00删除回执、20:01删除导出、20:02完成任务；随后恢复为`0 */5 * * * * *`并在原生云控制台读回。正式业务时限30秒、维护60秒没有改变。

本地测试缓存已精确移除。测试服务关闭配置已实际增量部署，服务器原有测试密钥保留不变，只关闭启用标记；部署任务成功后，真实健康返回configured=false，登录返回NOT_IMPLEMENTED。正式函数同批健康检查仍configured=true、releaseVersion=0.3.0-rc2；没有重新上传客户端。
