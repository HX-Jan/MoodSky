# MoodSky 团队体验版 · 0.2.3.1026

基于最新整合主干 `f793c0b476a69a809b3c156b49733f70cbc8facc` 整理，用于备案前团队内部体验。应用版本/API 沿用 0.2.3 / 1；上传版本为 0.2.3.1026。不提交审核或发布正式版。

## 本轮体验调整

- Today、私人记录和回顾统一说明保存范围，完整保留晴天、多云、阴天、雨天、雷雨、台风、自定义七项天气及原保存、修改、删除、重试行为。
- 面向体验者收起失败模拟、统计样例切换和装饰测试入口。既有开发演示模式保留原入口；体验模式必须显式开启且同时关闭云连接，不是正式业务开关。
- “我的”展示统一版本、使用步骤、隐私与反馈说明，不构造旧的本地合成账号，不展示模拟导出、注销、账号切换和健康诊断按钮。它不代表生产账号、导出或注销已开放。
- 校园页直接进入成员地点资料的本地预览，保留“待复核、不可导航”说明、筛选、分页、详情及固定天气示意；收起未连接的云读取、定位验证、纠错和支持资源诊断按钮。
- 轻任务沿用示例建议与自愿操作，将演示登录按钮改成“开始本次任务体验”。本版本不预填任务完成历史；仅展示本页实际操作，离开后清空。
- 月份档案不再额外加入用于检查空态的固定空月；真实无记录时显示下一步说明。预置日记示例仍保留，所有回顾页明确标注“记录与示例仅本次保留”。

## 数据与部署边界

这是内存功能体验包。天气、标签和正文不上传云端，也不写入本机持久化缓存；关闭运行时后可能丢失，不能用于长期保存。示例记录不是体验者的历史记录。真正的云端记录能力此前只完成获准的本人受限验证，测试入口已恢复关闭，不因本次上传重新启用。

没有修改后端业务代码、数据库、共享契约、天气枚举、云资源配置或生产权限。默认开发模式中已有的本地合成账号偏好缓存保持原逻辑；新的体验“我的”不读取或修改该缓存。本版本不自动请求定位。
