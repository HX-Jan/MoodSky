## 开发与生产入口

- 本地：Node.js 24，根目录运行npm ci、npm run setup；完整检查前安装cloudfunctions/moodsky依赖并运行npm run cloud:prepare。npm run team:check是九组终端合成联调，无网页/服务器/真实云权限验证。
- 共享契约源在miniprogram/shared；云端shared由命令生成。不要手改生成副本。
- 正式客户端必须用npm run release:package生成到仓库外的新目录；默认连接moodsky-release，维护目标moodsky-release-maintenance。普通源码个人配置默认关闭云能力。
