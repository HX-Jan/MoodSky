# 当前小程序原生与真机操作单

执行人先填写环境。模拟器和手机各填一份；已有901项本地检查、网页原型和旧体验包不能替代本表。

| 必填环境                 | 实际记录                                 |
| ------------------------ | ---------------------------------------- |
| 执行人、实际日期         | 待真实填写                               |
| 完整构建SHA/候选文件哈希 | 待核对本轮验证记录；不能只填0.2.3        |
| 模式                     | 开发内存/体验内存/其他获准范围，明确选择 |
| 工具与基础库版本         | 待真实填写                               |
| 手机型号、系统、微信版本 | 待真机填写；模拟器返回机型不是手机证据   |
| 字体/读屏/网络设置       | 待真实填写                               |

每条结果记录：实际步骤、预期、实际结果、通过/失败/未执行、截图或录像文件、执行人。只输入合成文字，不输入真实日记。

| 用例                  | 按页面执行的最小步骤                                                               | 合格标准                                                                          | 责任人                            |
| --------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------- |
| N01 天气必选/文字可空 | 打开没有记录的日期；不选天气看保存；选晴天，正文和标签保持空白后保存               | 未选择时不可保存并说明原因；选择后可保存，明确仅本次演示/未上传                   | Yifan                             |
| N02 CUSTOM边界        | 选自定义，分别输入空白、20个emoji、21个emoji，再输入合成名称                       | 空白/超长不保存；20码点可用；切回普通天气不残留名称字段                           | Yifan；Zhifeng核对投影            |
| N03 未知结果          | 在本地测试副本使用明确标注的合成响应丢失情境；观察输入、按钮和重试                 | 不把未知说成确定未保存；保留名称/正文和原请求，只重试原操作                       | Yifan                             |
| N04 草稿保护          | 私人记录输入合成正文；点重新读取→保留；再点重新读取→明确放弃                       | 取消保留原输入；确认放弃后才重新读取，不把草稿带到另一日                          | Yifan                             |
| N05 手机返回/生命周期 | 分别用系统返回、边缘手势、隐藏/返回；观察未保存和未知结果；记录API不支持时实际提示 | 记录真实保护或降级效果；丢失或覆盖即记失败，不用模拟器替代                        | Yifan；Linghan配合                |
| N06 键盘/小屏         | 在小屏上输入长中文和emoji，打开键盘，尝试查看说明、错误、保存与取消                | 控件可见或可滚动到达，无关键遮挡或截断                                            | Yifan；四页面负责人各核对所属页面 |
| N07 自愿任务          | 从需求入口取消/暂时不做；打开任务再跳过                                            | 不自动保存日记、不自动选/完成任务；体验建议与真实任务分开                         | Yifan、任务负责人                 |
| N08 私人回顾          | 保存合成正文和CUSTOM；返回Today，再看月历/月份卡片和本人详情；找一个无记录月份     | 摘要/卡片无正文；详情按范围显示；空月份与读取失败不同；私人名称不进入公共校园天气 | Zhifeng；Yifan                    |
| N09 Campus            | 不授予定位仍浏览；核对地点来源/核验提示与固定模拟天气；查看未核验地点导航          | 拒绝定位不阻断基本浏览；未核验不可导航；不声称真实聚合                            | Qinghan                           |
| N10 Me模式边界        | 对照开发与体验实际入口，核对偏好、导出、注销说明                                   | 不把开发演示入口写成体验功能；隐藏入口不证明跨页偏好已集成或正式生命周期已通过    | Linghan、Zhifeng                  |
| N11 正式隔离另验      | 由服务负责人按另外获准的环境执行真实A/B账号、迟到响应、公共投影                    | 由真实证据关闭；内存演示和隐私标签不证明权限隔离                                  | Xiang Hong/服务负责人、独立复核人 |

N03本轮自动化仅注入内存服务响应丢失，不能叫真实断网。N05/N06/N09的手机授权与手势仍需手机实际执行。本轮不会为完成N11开启云端或复用历史云写授权。

发现失败时保留修前证据，再登记修复提交和同一用例的修后证据。与[可访问性操作单](accessibility-checklist.md)可在同次设备会话执行。
