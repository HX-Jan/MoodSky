## 4. 已修复问题

### F1 详情页 stale 空态返回指引错误

- 现象：从“档案 → 月份档案”进入详情后，若该记录被删除并重建，stale 空态提示“请返回月历，打开最新记录。”，但用户并不在月历链路。
- 影响：不阻塞阅读（返回按钮可用），但返回指引与实际导航栈不一致，影响操作。
- 修复：`miniprogram/pages/review/detail/index.wxml` 改为“请返回上一页，重新打开最新记录。”
- 验证：文案无测试断言依赖；`npm run check` 通过。

## 5. 非产品问题与已知项

### T1 测试工具误报：B 账号写入落到 A（已排除，非产品缺陷）

- 初次编写 Z04 时使用 `f.save({...})` 保存 B 账号数据，随后以 B 读取为 0，疑似账号隔离失效。
- 根因：`tests/helpers/backend-client.js` 展开 `backend` 的 `save` 方法，而 `backend.save` 默认 `actor='a'`，不读取 `setActor()` 设置的闭包变量；写入实际发生在 A。
- 处理：B 账号改为 `f.call('journal.upsert', payload, { actor: 'b' })`。修正后 B 读写一致，A/B 隔离用例通过。
- 结论：测试工具使用问题，不是产品缺陷；未修改产品代码。

### E1 快照环境准备

- 现象：初始快照无 `.git`、无云函数依赖，`npm test` 在 `require('wx-server-sdk')` 处失败。
- 处理：初始化本地仓库、安装根依赖与 `cloudfunctions/moodsky` 依赖、执行 `npm run cloud:prepare`。
- 结论：环境问题，不是产品缺陷。

### G1 云端“档案”落地页缺少月份目录

- 现象：云端模式只提供月份选择器，`months=[]`，不展示各月记录数。
- 依据：`pages/review/archive/index.js` 注释与 `w1-h04 §3.4` 已记录该缺口；月份档案页（`review/month`）本身同步一致。
- 处理：本轮不实现新的月份目录接口，避免超出 W5-R02 的同步验证范围；记录为后续能力项。

## 6. 旧数据回填排除说明

1. 所有 W5 用例只走云函数 reader，不加载 demo store/service；加载器对 demo 读取计数，任何调用直接失败。
2. 删除后断言四页面 JSON 不含原记录名称、正文或“合成演示”内容。
3. 空态用例断言云端档案页不生成 demo 空月目录。
4. 重建用例断言旧 ID 详情为 stale，且正文为空。

## 7. 建议的复测顺序（真机可用后）

1. 同一账号在同一日期新增 → 编辑 → 删除 → 重建，依次进入月历、档案、详情、7/30/90 天回顾核对 ID/天气/名称。
2. 9 月 30 日与 10 月 1 日各建一条，检查 9/10 月隔离与 30/90 天窗口。
3. 删除某月最后一条，确认月历与档案归零且不出现演示数据。
4. A/B 两个真实账号同日各一条，切换后核对清空、stale 与切回恢复。
