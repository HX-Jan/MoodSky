# Week 5 GitHub 提交说明

解压后，压缩包内的两棵目录对应 GitHub 仓库根目录。建议提交标题为 `fix(w5-jq): 调整首页日期与状态提示`。

| 文件                                                                 | 上传位置                   |
| -------------------------------------------------------------------- | -------------------------- |
| `README.md`、`W5_Jiaqi_Zhu_交付报告.md`、`PR_BODY.md`、`提交说明.md` | `docs/week5/jiaqi-zhu/`    |
| `index.js`、`index.wxml`、`index.wxss`                               | `miniprogram/pages/today/` |

1. 已有本次 Week 5 分支或 PR 时，沿用原分支。首次提交可从团队主分支创建 `codex/jiaqi-today-ui`。
2. 网页提交时，在仓库的个人分支打开 `docs/week5/`，通过 **Add file → Upload files** 上传解压后的 `jiaqi-zhu` 文件夹。再打开 `miniprogram/pages/today/`，上传三个首页源码文件。
3. 源码包基于 `28f810c`。若你的分支已经对这三个源码文件有其他修改，请按报告里的改动合并，保留分支已有代码。
4. 向 `main` 发起 PR，正文复制 [PR_BODY.md](PR_BODY.md)，检查 **Files changed** 中的文件路径。只需交个人周报时，可单独上传 [W5_Jiaqi_Zhu_交付报告.md](W5_Jiaqi_Zhu_交付报告.md)。

压缩包用于下载和交接，GitHub 提交使用解压后的文件。
