## 3. 演示顺序与每步预期

1. **当前月空态**：打开天气宇宙，默认 2026-11。预期 0 条、“本月暂无记录”，日期格子留白，不补天气。
2. **切到有记录月份**：选择 2026-10。预期 5 条，10-16 为雨天；网格 31 天、5 周。
3. **进入详情**：点 10-16。预期详情显示雨天、v1 与种子正文；这是唯一出现正文的入口。
4. **返回并看档案**：回到 2026-10，打开月份档案。预期 5 张卡片、按日期倒序、卡片无正文；首卡 10-16。
5. **看回顾**：打开 90 天回顾。预期窗口 2026-08-24—2026-11-21，7 条时间线，按日期倒序；分布与种子一致。
6. **切到非当前月并刷新**：选择 2026-09，下拉刷新。预期仍为 2026-09、2 条，不跳回当前月。
7. **看空月**：选择 2026-08。预期 0 条、“本月暂无记录”，31 个日期留白。
8. **可选：修改／删除传播**：在 Today 页把 10-16 改为雷雨后回四入口确认；再删除，确认月历与档案减少、旧详情变 `missing`、回顾不再出现该日。
9. **可选：旧响应说明**：口述 C3 的挂起—切换—释放时序，展示 `stale-response-results.csv`；不建议现场手点复现。

## 4. 重置方式

- 演示数据在进程内，关闭当前运行并重新执行页面即回到 7 条种子。
- 重新生成全部素材：

```bash
node tools/week6-z/alpha-review-harness.cjs --cycle c4 --out docs/alpha-sprint/zhifeng-dai/c4
```

- 全量检查：`npm run check`。
