# 账号、分享与导出模块演示步骤

适用环境：**禁云本地预览构建**（最终源码的隔离预览副本）。只演示该环境已实际通过的功能；真实微信登录、真机文件送达、原样候选端云联调不现场演示，用本文件标注的备用素材代替。

## 演示路线（约 2 分钟）

| 步  | 入口与操作                                | 展示点                 | 预期画面                                       |
| --- | ----------------------------------------- | ---------------------- | ---------------------------------------------- |
| 1   | 打开小程序（游客态）→ 首页「今天」        | 游客可直接浏览公开内容 | 七天气首页正常，无登录强制弹窗                 |
| 2   | 切到「我的」→ 点「账号与数据」            | 私人入口先登录         | 跳转登录页，顶部显示脱敏后的来源页信息         |
| 3   | 登录页不勾选同意点登录                    | 同意前置校验           | 提示「请先阅读并同意隐私保护指引。」           |
| 4   | 勾选同意后登录（本地为合成会话）          | 登录成功回到目标页     | 提示「登录成功」并进入账号与数据页             |
| 5   | 「我的」查看个人资料入口                  | 可选资料               | 未设置头像昵称时显示「微信用户」与默认头像     |
| 6   | 账号与数据页申请 JSON 导出 → 查看导出内容 | 应用内预览             | 分页预览本人导出内容，不落盘                   |
| 7   | 保存导出 → 选择取消                       | 取消反馈               | 「已取消发送，可重新领取文件。」，导出仍可重试 |
| 8   | 退出登录                                  | 会话清理               | 预览清空、回到游客态，记住登录标记清除         |

## 演示数据与重置

- 使用界面内直接新建的合成记录（如「演示用」一条），或预览副本自带的 demo 数据；演示前在记录页删除旧演示数据即完成重置。
- 登录态重置：退出登录即可；如需完全复位，关闭预览副本重新打开。

## 故障备用素材

- 全部分支行为的自动化证据：`docs/alpha-sprint/l/c4/evidence/c4-linghan-final-recheck.tap`（37 项通过）。

- 若现场登录或导出不可用：改讲述 c1/c2 结果表中的分支覆盖（成功／取消／失败／兼容文本），并展示 TAP 日志，不冒充真机结果。
