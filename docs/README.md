## 哪些内容可以更新

现行入口、索引、维护者说明可以随新交付更新，并标明固定基线。成员原始报告、截图、原日志和个人工时/估点/签认不为统一格式而改写；发现差异用独立审查记录解释。保留已有目录名，使用入口链接统一导航，不为大小写批量搬动材料。

新说明采用清楚的标题和相对文件链接，不复制一套天气、action或错误枚举作为新权威。`npm run docs:check`核查维护入口中的本地文件链接；它不验证远端网页、锚点语义、资料真实性或云端状态。
