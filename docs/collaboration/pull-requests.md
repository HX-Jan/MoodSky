## 如何查到原始贡献

[完整来源 JSON](registry.json)分别保存原始首提交、原交审快照、最终head、合并提交、后续接收PR、原作者和实际审批记录。首次提交与首次交审不是同一概念；最终diff可能含整合人追加修正，不能把整份diff或提交次数记为某个成员的工作量。

原始提交、已有文件名、证据和讨论都保留。原稿与最终交审的取舍继续以链接的逐项审查为准；本轮自动核对“文件仍在”不等于重新证明每项界面/云业务已可用。初始化提交 `ad1e453` 是38次PR合并之外的唯一主干起点，不为追溯形式补造历史PR。
