## 先区分四件事

| 状态              | 含义                             | 不能据此推断                           |
| ----------------- | -------------------------------- | -------------------------------------- |
| 已提交/补交       | 找到实际文件、提交或PR           | 完整实现、按时完成、独立验收           |
| 已合并/经整合收录 | main有对应提交或明确接收PR       | 生产环境已启用、成员工时已确认         |
| 已接入            | 入口和调用链有对应验证记录       | 真实云端、设备和权限已通过             |
| 已验收            | 指定人员按实际环境完成并记录结论 | 由整合人代签、用CI或访谈稿代替真实执行 |

任务状态统一为“待开始、进行中、待复核、已验收、阻塞”。收件、PR状态和证据环境单独记录；没有报告的地方标“待本人回传”，不推定没有工作。原个人工时、项目估点、独立意见和签字不改写，也不按代码行数或PR数量分配贡献比例。
