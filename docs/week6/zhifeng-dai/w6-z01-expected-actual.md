补充规则（由用例断言，不依赖人工观察）：

- 月历 `monthSummary`：有记录为「本月 N 条记录」，空月为「本月暂无记录」。
- 档案卡片按日期**倒序**，且不含正文，避免列表页泄露详情内容。
- 详情页只在详情页展示正文；记录删除后详情页进入 `missing` 态且正文为空。
- 月历/档案的天气标识数量必须等于该月记录数；空白日不得被渲染成「阴天」。

## 5. 跨页面一致性规则

四个页面读取的是同一份快照（同一 `store` / 同一会话），因此一致性判定为：

1. 同一天的 `id`、`weather`、`label` 在月历与档案中必须完全相同；
2. 月历 `monthRecordCount` = 档案 `recordCount` = 该月记录数；
3. 详情页 `id` 必须属于该日期，正文与版本取自同一条记录；
4. 回顾时间线条目 = 落在窗口内的同批记录，分布计数逐项等于时间线条目统计。
