# 第一版素材来源与使用说明

七类预设天气图标及自定义星星图标、校园示意插画、装饰线条和界面小图标均在本次设计中原创绘制为 SVG，没有临摹参考产品角色，也未使用第三方图标库、照片或付费素材。

本次交付的原创图形可由本项目团队使用、修改、缩放和导出，用于小程序、项目预览、设计规范与项目展示；无需引用第三方图标作者。请不要将字体文件或 Figma 品牌资源混入原创素材许可。

| 文件 | 界面名称 | 文字配对 | 图形来源 |
|---|---|---|---|
| `weather/SUNNY.svg` | 晴天 | 此刻比较轻松、愉快 | 本项目原创 SVG |
| `weather/PARTLY_CLOUDY.svg` | 多云 | 还不错，也有一些起伏 | 本项目原创 SVG |
| `weather/CLOUDY.svg` | 阴天 | 平淡、疲惫或有点闷 | 本项目原创 SVG |
| `weather/RAINY.svg` | 小雨 | 难过或想安静一会儿 | 本项目原创 SVG |
| `weather/STORMY.svg` | 风雨 | 有些难熬，需要更多照顾 | 本项目原创 SVG |
| `weather/HEAVY_RAIN.svg` | 暴雨 | 感受很强烈，想慢慢缓一缓 | 本项目原创 SVG |
| `weather/TYPHOON.svg` | 台风 | 感受交织，想给自己一点空间 | 本项目原创 SVG |
| `weather/CUSTOM.svg` | 自定义 | 用自己的名字表达此刻的感受 | 本项目原创 SVG |

每个天气源图64×64、透明背景，图标与文字同时出现。建议界面使用24/32/48/64px；素材放大仍为矢量。选中态另有品牌色描边，不能仅靠底色区分。天气名称及含义来自用户提供的功能方案；这些含义是选择提示，不是诊断或评估。

交付 SVG 的透明区域保留透明，适合在 Figma 中继续编辑形状与颜色。需要 PNG 时，在 Figma 选中素材后 Export → PNG，选择1×/2×/3×；48px显示的素材可导出96px（2×）或144px（3×）。完整贴纸和背景库本周未制作。

界面推荐 Noto Sans SC，备用思源黑体 / PingFang SC / 微软雅黑，最后回退 Inter。字体文件未包含在设计包，需使用已有安装或从字体官方来源获取，并保留其许可。原型预览使用当前设备可用的字体，Figma 插件报告实际字体。

地点图片为原创**示意插画**，不代表真实学校外观；正式校区图片和地点信息由负责人提供并核实来源。
