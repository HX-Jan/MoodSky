## 当前工程采用什么

共享天气以 [代码常量](../../../miniprogram/shared/constants.js)为准：SUNNY 晴天、PARTLY_CLOUDY 晴间多云、CLOUDY 阴天、RAINY 雨天、STORMY 暴风雨。标签、日期、版本与私人记录规则继续以现有共享约定及 H02 为准。无记录日期保持留白，不能使用 CLOUDY 填充。

本设计的 HEAVY_RAIN、TYPHOON、CUSTOM 及八项布局属于扩展提案，尚未批准；素材保留供设计比较，不写入数据字典或保存/统计白名单。设计 tokens 也是候选，需 Linghan 与各页负责人核对后再单独接入。插件导入不会改变当前小程序。

Today 两步表单以已有实现和 Yifan 交接为准；宇宙页采用私人月历/档案/统计的演示路径。设计原型的自定义天气、导出、注销、后台、任务、定位等页面不能据此宣布真实业务完成。

## 本次实际核对

本地执行 figma-import/verify-local.js 校验设计数据及导入器契约，执行 verify-mock.js 验证合成 Figma 对象上的导入、连线及重复导入行为。结果另记发布报告。浏览器旧检查和 PNG 保留成员原记录时点；本次没有在真实 Figma 编辑器导入，没有新增真机或访谈成绩。

研究目录现已包含提纲、排期、P01—P06 空白记录、12 人汇总和前端评审模板。它们均为准备材料，招募、同意、访谈、汇总及实际评审结果仍待本人提供，不能填为已完成。

## 组员怎么使用

1. 先看 README 中的离线原型，再对照本页确认哪些画面属于工程基线、哪些仅供讨论。
2. 前端实现五类天气时使用工程常量，不从设计源数据反向生成正式枚举或请求字段。
3. 需要改天气、tokens 或交互时，在 PR 中列出差异、影响的接口/页面及评审人，获确认后再更新工程。
4. 研究成员填写真实记录和证据，保留尚未执行项；不把模板、模拟数据或导入器测试作为用户反馈。
