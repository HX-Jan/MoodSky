本设计的 HEAVY_RAIN、TYPHOON、CUSTOM 及八项布局属于扩展提案，尚未批准；素材保留供设计比较，不写入数据字典或保存/统计白名单。设计 tokens 也是候选，需 Linghan 与各页负责人核对后再单独接入。插件导入不会改变当前小程序。

Today 两步表单以已有实现和 Yifan 交接为准；宇宙页采用私人月历/档案/统计的演示路径。设计原型的自定义天气、导出、注销、后台、任务、定位等页面不能据此宣布真实业务完成。

## 组员怎么使用

1. 先看 README 中的离线原型，再对照本页确认哪些画面属于工程基线、哪些仅供讨论。
2. 前端实现五类天气时使用工程常量，不从设计源数据反向生成正式枚举或请求字段。
3. 需要改天气、tokens 或交互时，在 PR 中列出差异、影响的接口/页面及评审人，获确认后再更新工程。
4. 研究成员填写真实记录和证据，保留尚未执行项；不把模板、模拟数据或导入器测试作为用户反馈。
