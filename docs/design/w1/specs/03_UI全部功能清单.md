# Moodsky 校园情绪天气｜UI 全部功能清单

版本：W1 v0.2；日期：2026-10-14。范围：本次交付的四页 UI、主要可点击路径、说明与异常状态、后台低保真，以及新增的暴雨、台风、自定义天气。

这是一款帮助学生低负担记录当下感受、回顾私人记录、发现校园地点及自主选择小任务的工具。天气由用户选择，不代表真实气象预报、情绪评分或心理诊断。

## 本次新增

“选一种最贴近此刻的天气”由五个选项扩展为八个入口：**晴天、多云、阴天、小雨、风雨、暴雨、台风、自定义**。暴雨和台风与其他天气具有相同的记录、保存、详情和编辑路径；选择它们不自动公开、报警或触发任务。

自定义允许输入 1–10 个 Unicode 字符的名称，并从预设天气图标和配色中选择组合。提供预览、确认、重置和取消；例如可以命名为“雨后初晴”。当前不包含上传图片、绘图或输入任意色值。自定义也是私人记录，并在回顾、编辑和导出设计中保留名称、图标和配色。

## 如何理解当前交付状态

| 状态              | 含义                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------- |
| 可点击流程        | 按钮、Tab 或热点可切换到对应示例画面；属于原型演示。                                   |
| 本地交互          | 浏览器内可以编辑自定义天气并即时预览；不连接账号和数据库，不代表已经保存到正式小程序。 |
| 静态设计 / 低保真 | 图层、字段、规则或组合状态已设计，但没有完整可操作业务控件。                           |
| 待实现            | 正式登录、真实记录、定位、导航、反馈、下载和删除等需要前后端接入与验收。               |

下表逐项说明目前画面能做什么，以及正式产品还需要实现什么。所有用户、地点、天气卡、任务编号和处理状态均为示例。当前没有真实访谈结果或前端评审通过结论。

## 9. 尚未加入本轮 UI 的功能

公开树洞、公共投稿、校园群体天气汇总及独立贡献/撤回流程、完整贴纸与背景库、3D 天气宇宙、AI 情绪分析或诊断、排行榜、连续打卡、真实气象预报，没有在本轮开放。趋势统计图、搜索、任意年份跳转、取消收藏、真正的在线导航和学校预约，也不能从现有说明页推断为已完成。

正式实施时，自定义天气应作为记录的独立数据字段保存，避免用户后来重命名而改写历史卡。导出应保留当时的名称及可还原的图标/配色标识；普通保存仍不会触发公开或校园统计。导出有效期、删除处理时间、备份清理和失败补偿以实际服务端能力确认，本轮不作完成时限承诺。
