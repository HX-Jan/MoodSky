# Moodsky 校园情绪天气｜第一版视觉与交互规范

版本：W1 v0.2；日期：2026-10-14。依据本次 `design/design.json`、组件库与方案建议编写，供首轮设计和实现评审使用。颜色与代码 token 的对应关系待 Linghan 核对；本文件不代表已有实现或测试通过。

## 1. 风格与尺寸

界面采用奶油白底、深色文字、柔和天气色、原创 SVG 天气形象与圆角纸卡。视觉服务于低负担记录、私人回顾和校园地点发现；不使用情绪等级、连续打卡或比较排名。

移动端设计基准为 **390 px 宽**，常规画面高 844 px，地点详情高 980 px；内容左右各 24 px，常规内容宽 342 px。后台低保真画面为 1440×960 px。实际小程序需采用滚动内容及系统安全区，不锁死截图高度。

转换到 750 rpx 画布时使用 `rpx = 设计px × 750 / 390`，比例约 **1.92308**；例如 16 px≈30.77 rpx、24 px≈46.15 rpx、44 px≈84.62 rpx、48 px≈92.31 rpx。不能套用 375 px 画布的 2 倍换算。字体放大、键盘、底部安全区与小屏布局仍需真机复核。

间距以 4 px 为基本单位，已定义 4 / 8 / 12 / 16 / 24 / 32。圆角 token 为 12 / 16 / 20 / 24 / 28；天气选项、输入和按钮常用 16，记录卡常用 20，强调背景可用 24。细描边通常 1 px，天气选中描边 2 px。

| 文字 / 背景组合                       |                         对比度 |

## 3. 字体与组件

设计字体优先 Noto Sans SC。导入工具依次查找 Noto Sans SC、Source Han Sans SC、PingFang SC、Microsoft YaHei、Noto Sans CJK SC、Inter；可用字重不足时回退，导入后需核对中文与换行。**素材包不含字体文件**。小程序使用系统中文无衬线字体；字体及字重差异需人工检查。

| 层级                   | 字号 / 行高（设计 px） | 字重             |
| ---------------------- | ---------------------- | ---------------- |
| 主要页面标题           | 28 / 42                | Bold             |
| 标题规范基线、强调标题 | 24 / 36                | Bold             |
| 区块标题               | 20 / 30；18 / 27       | Medium           |
| 正文、按钮标签         | 16 / 24                | Regular / Medium |
| 辅助说明               | 14 / 21                | Regular / Medium |
| 日期、非核心元信息     | 12 / 18                | Regular / Medium |

封面与后台存在更大展示字，不作为移动端正文标准。重要隐私说明、错误与关键操作不得只用 12 px 小字。

实际组件包括：Button（Primary / Secondary / Quiet / Danger / Disabled / Loading）、WeatherChoice（八项天气×默认/选中）、FilterChip（默认/选中）、Input（默认/焦点/错误）、Toggle（开/关）。其余业务卡为可编辑图层组合。

按钮基准 342×48 px；其他交互目标至少 **44×44 px**。天气组件基准为 72×80 px，首页采用4列×2行，实际选择区约71.5×80 px，筛选组件高 44 px。开关视觉为 52×32 px，外层点击区域至少高 44 px。禁用保存同时说明“先选一种天气”；加载态阻止重复提交。输入基准 342×112 px，文字选填，上限 1,000 个 Unicode 字符，标签最多 5 个；字符计数与后端策略待统一。

## 5. 交互与状态约定

四个 Tab 为今天 / 校园 / 天气宇宙 / 我的。初次记录允许只选天气直接保存；标签、正文可空。每人每日一条，再次保存进入修改。成功文案为“已收好，只有你能查看这条记录”。记录详情、宇宙和数据页保持私人范围说明，并说明服务端必要受控处理。

保存中显示进度；断网保留本页编辑内容、明确尚未保存并提供重试；离开未保存页先说明影响；登录过期需重新登录；版本冲突不得静默覆盖。原型有对应状态画面，实际判断与草稿恢复由前后端实现，不默认长期缓存私人正文。

地点列表默认不使用定位，筛选按选中条件同时满足；定位、导航由用户主动选择。地图失败保留列表，关闭或施工地点明确标记。任务最多展示 3 项，均有预计时长、场景及替代方案；用户可完成、换一个或今天不做，不要求照片或 GPS 证明。

宇宙只使用本人已保存记录；空白不补齐，空态不催促。卡片与月份切换不生成心理结论。导出有处理中、可下载、过期和失败；删除及注销有确认和处理中，不提前宣告完成。动效实现建议 150–250 ms，并尊重减少动态效果；关闭装饰仍可完整记录与回顾。

所有地点、记录、任务、账号与任务编号均为原型示例；真实信息需由对应负责人提供和核验。

## 6. 新增天气与自定义规范

| Token     | 色值    | 用途           | 深色正文对比度 |
| --------- | ------- | -------------- | -------------: |
| heavyRain | #A8BCD9 | 暴雨背景       |         6.73:1 |
| typhoon   | #B5A8C9 | 台风背景       |         5.83:1 |
| custom    | #DCEACF | 自定义默认背景 |        10.36:1 |

所有天气卡上的私人范围文字及图标统一使用深色正文色，避免绿色小字叠在较深的天气底色上。天气仅是表达方式，新增暴雨/台风不对应心理等级、风险评分或自动求助。

自定义名称去除首尾空格后计数，1–10个Unicode码点，不计作诊断标签。图标可选晴天、阴天、小雨、旋风、星星；底色6种，均配深色正文。默认图形为原创星星，Figma样例为“微风”。即时预览、确认、重置、取消和编辑恢复在浏览器演示；状态仅存当前页面内存。

自定义标题最长10字时，保存卡用24px、详情20px、月份卡15px，以保持可读。月历仍用图标和“自定义”类别图例，完整名字在卡片或详情中查看。真实应用应逐条保存名称、图标、颜色的快照，修改一条记录不能改写其他记录。
