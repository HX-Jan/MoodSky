# Moodsky 校园情绪天气 · 第一周 UI / UX 设计包

> 整合提醒：这是设计提案和研究准备包；正式小程序仍为五类天气。原型中的暴雨、台风、自定义及其 tokens 尚未获批接入。真实访谈、Figma 编辑器和前端联合复核尚待执行，详见 [整合说明](INTEGRATION.md)。

已制作 Today、Campus、Universe、Me 四页首轮界面与主要点击路径，补充任务选择、异常状态及后台低保真布局。设计以奶油白、灰绿和八项天气的柔和底色构成；天气记录与宇宙回顾默认私人，地点浏览不依赖定位。

本包为 W1 v0.2，日期 2026-10-14。所有记录、地点、时间和任务状态均为演示数据。前端评审、Linghan token 核对和真实访谈尚未执行。

## 先看设计

- 双击 `preview/index.html`：打开离线可点击原型，左侧有六个流程起点。
- 打开 `preview/四页总览.png`：查看四个主页面。
- `screens/`：独立页面 SVG，含主要页面和补充状态。
- `specs/`：视觉与交互规范、前端交接、待确认事项。

这份原型通过画面跳转演示交互。正文输入、定位、登录、导出和注销没有接入真实服务。自定义天气可在浏览器中输入名字、选择图标和底色；仅保存在当前页面内存，刷新后清除，不写入数据库或本地存储。画面里的操作可以继续在 Figma 中修改。

## 在 Figma 里编辑

**方式 A：直接拖入 SVG，最快查看和修改矢量形状。** 将 `figma-import/Moodsky_W1_四页直导.svg` 拖到 Figma Design 画布，或拖入 `screens/` 中的单页 SVG。SVG 的文字可能转为轮廓；需要编辑文案、组件和原型连线时，使用方式 B。

**方式 B：原生设计导入，推荐。**

1. 解压整个设计包，打开 Figma Desktop，创建 Figma Design 文件。
2. 在 `Plugins → Development → Import plugin from manifest…` 选择 `figma-import/manifest.json`。
3. 运行「Moodsky · 第一周 UI 导入」，选择 `design/design.json`，点击「创建可编辑设计」。
4. 完成后检查插件报告中的字体及未完成连线，再关闭窗口。设计包含三页：开始与视觉规范、主要可点击原型、后台低保真。主组件放在规范页右侧。
5. 原型页已有五个移动端流程起点，后台页有一个起点。选择起点后点 Present 查看；可通过 Share 给前端发送可点击链接。

若本地开发插件 ID 被拒绝，`figma-import/README.md` 提供先在 Figma 创建开发插件、保留 Figma 分配的真实 ID、替换代码的备用步骤。无需发布插件。

设计文字作为原生文字层，天气图标为矢量层，按钮等为原生组件实例；有 Auto Layout 容器、语义颜色变量和文字样式。建议使用 Noto Sans SC；插件会优先检查实际字体，也可用思源黑体、苹方或微软雅黑。包内未捆绑字体。

本包不是 `.fig` 二进制文件；Figma 在线连接反复返回认证重试，因此没有伪造在线设计链接或 `.fig`。导入后可从 Figma 的 **File → Save local copy** 保存真正的 `.fig`，再供他人导入。[Figma 官方本地副本说明](https://help.figma.com/hc/en-us/articles/8403626871063-Save-a-local-copy-of-files)。

## 已完成的检查及边界

已检查源数据 ID、组件依赖、点击目标、布局边界和文字高度；浏览器执行主要路径并导出预览。常用正文组合对比度超过 4.5:1，主按钮高48px，其他点击目标通过独立热区至少44×44px。宽度390px设计稿换算到750rpx，应乘以750/390。

本地 Figma 导入逻辑通过模拟集成检查，包括文字字体加载顺序、颜色变量、窄按钮、原型连接和重复导入保留页面。**尚未在真实 Figma 编辑器执行**，所以导入后的字体、画布渲染及原型运行仍以实际报告和复核为准。浏览器检查不代表小程序真机、性能或用户可用性达标。

原方案 §7.3 的“天气宇宙”线框误用了公开投稿表单；本设计采用 FR-04 与 §20–22 的私人月份回顾定义。此差异列入负责人确认项。

## v0.2 更新

天气选择新增暴雨、台风、自定义，采用两行四列。暴雨与台风有各自原创图标、底色、含义和保存/编辑/回顾画面。自定义支持1–10个Unicode字符的名称、5个原创图标、6种底色、即时预览、输入校验、重置、取消和再次编辑。

保存卡、记录详情、编辑及月份卡片跟随选择展示名称、图标和底色。历史记录切换天气仍保留原日期；自定义返回/取消回到原编辑页。Figma 的自定义页面是可编辑的默认“微风”样例，真实文字输入与选色在浏览器预览中演示。

完整功能与当前实现边界见 `specs/03_UI全部功能清单.md`，包括55项分模块说明。公开树洞、校园群体天气、完整装饰库及趋势图没有加入当前UI。
