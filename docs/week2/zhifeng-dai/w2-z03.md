## 1. 同步链路

| 操作（记录页）      | 月历                                                | 月份档案                            | 详情                                                                     |
| ------------------- | --------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------ |
| 保存 / 修改         | `onShow` 重读 `review.calendar`，月度统计与卡片刷新 | `onShow` 重读 `review.monthArchive` | `onShow` 重读 `journal.get`（带 `entryId` 核对）                         |
| 删除                | 同上，回到空月/空档案                               | 同上                                | 进入“不存在”态（missing），不展示缓存正文                                |
| 删除后重建（新 ID） | 新记录正常出现                                      | 新卡片正常出现                      | 旧 `entryId` → “过期”态（stale）；不带 id 的入口 → 正常 ready 展示新内容 |

## 2. 场景覆盖（tests/review-week2.test.js）

| 验收点                 | 用例                                                                               | 断言要点                                                                       |
| ---------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 跨页刷新               | `delete syncs universe, archive and detail; recreated records open fresh ids only` | 删除后逐页 `onShow`：月历归零、档案清空、详情 missing                          |
| 删除后缓存不复活       | 同上                                                                               | `detail.data.text` 为空、phase=missing，缓存正文不回显                         |
| 旧 ID 兼容             | 同上                                                                               | 重建后旧 id → `phase=stale` 且正文为空；无 id 入口 → `phase=ready` 展示新正文  |
| 记录不存在 vs 读取失败 | missing 态（上例）+ `review-pages.test.js` 停用账号用例                            | 不存在 → missing 空态；账号停用 → 明确的“账号已停用”错误态，二者文案与状态分离 |
| 过期响应               | `late cloud calendar response cannot replace a newer month selection`              | 迟到响应被序列令牌丢弃                                                         |
| 页面卸载               | `unloaded detail page discards a late cloud response`                              | 卸载后到达的 `journal.get` 响应不渲染正文，页面保持初始态                      |
| 账号切换无残留         | `account switch clears prior private review content on the next show`              | 切到账号 b 后月历/档案/详情全部重读为 b 的空数据，页面数据中无 a 的正文        |

既有覆盖（W1 用例继续生效）：`tests/review-cloud-pages.test.js`（hide 后丢弃挂起响应、删除重建旧卡 stale）、`tests/review-pages.test.js`（演示模式跨页同步、卸载丢弃）。
