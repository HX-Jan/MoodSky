## 2. 云模式装饰三态（本次新增）

| 状态          | 触发                                     | 页面表现                                                                                               |
| ------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| available     | 契约 get 成功（未来后端实现后）          | 按服务端返回渲染背景 / 贴纸 / 版本，只读展示                                                           |
| unimplemented | 后端返回 `NOT_IMPLEMENTED`（当前生产域） | 显示“云端装饰服务尚未开放，装饰暂不可读写；月历、档案与统计不受影响。”；同一会话不重复请求；无写入入口 |
| unavailable   | 网络失败 / 响应不完整等                  | 显示“装饰状态读取失败，已降级为默认展示；月历与记录不受影响。”，装饰数据清空                           |

## 3. 降级与隔离机制

- 素材加载失败降级：演示模式经 `onSimulateAssetFailure` 演练（贴纸降级为文字、默认背景）；云模式读取失败统一降级文案，月历与记录渲染不受影响（测试断言 `monthRecordCount` 与 `calendarError` 不变）。
- 旧月份响应隔离：装饰探测沿用 `_decorationSeq` 令牌，并新增“响应月份 ≠ 当前月份则丢弃”的核对；进入错误态时同步清空旧月份可能残留的贴纸 / 背景渲染，避免跨月串扰。
- 挂起探测（切月后到达的旧月份成功响应）被丢弃后允许重新探测当前月份（用例：stale month responses）。
