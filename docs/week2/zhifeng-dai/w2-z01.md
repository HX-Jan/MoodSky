## 1. 五个回顾入口的接口对照

| 入口     | 契约动作                                                                         | 候选后端（candidate-router + services/review.js）                        | 生产云函数（index.js 未接 domainHandlers） | 前端页面入口            |
| -------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------ | ----------------------- |
| 月历     | `review.calendar` `{ month }`                                                    | 返回日期升序entries、recordCount和sourceRevision；周网格与摘要由页面生成 | NOT_IMPLEMENTED                            | pages/universe          |
| 月份档案 | `review.monthArchive` `{ month }`                                                | 返回日期倒序cards及cardTextPreview:false；无分页参数                     | NOT_IMPLEMENTED                            | pages/review/month      |
| 分布     | `review.distribution` `{ windowDays }`                                           | 已实现（7/30/90 窗口，分母 = recordCount）                               | NOT_IMPLEMENTED                            | pages/review/insights   |
| 时间线   | `review.timeline` `{ windowDays }`                                               | 返回窗口内日期倒序items、recordCount、sourceRevision及trendEligible      | NOT_IMPLEMENTED                            | pages/review/insights   |
| 装饰     | `review.decorations` `{ operation: get/replace/reset, month, expectedVersion? }` | 已实现（expectedVersion 乐观锁）                                         | NOT_IMPLEMENTED                            | pages/universe 装饰面板 |
| 详情正文 | `journal.get` `{ date }`                                                         | 已实现（仅返回本人记录，正文只在详情页读取）                             | NOT_IMPLEMENTED                            | pages/review/detail     |

结论：候选后端五个入口 + 详情读取均可接入；生产云函数的 review 域与 journal 域尚未接线（`domains/review.js` 返回 NOT_IMPLEMENTED）。前端不得把候选契约宣传为已上线能力：生产模式下所有入口保持明确的“回顾服务尚未开放”阻塞标识（见 W2 Z04/Z05）。

## 2. 定稿的统计口径

| 项           | 定稿口径                                                                                          | 代码落点                                                                |
| ------------ | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 分布分母     | 窗口内实际记录条数 `recordCount`，不是窗口天数；无记录时分布为空态                                | `services/review.js` buildDistribution、`presentation.js` buildInsights |
| 分布展示     | 每类 `count`、`ratioText`（`n/m 条`）、`percent`（四舍五入）；空数据显示空态文案                  | presentation.buildInsights                                              |
| 时间线排序   | 业务日期倒序，每日最多一条，窗口最多90个自然日；没有sortAt、cursor或hasMore接口                   | `services/review.js`、`reader.js`                                       |
| 回顾窗口     | 仅 7 / 30 / 90 天（`REVIEW_WINDOWS`），页面 tap 切换并全量重读                                    | `shared/constants.js`、pages/review/insights                            |
| 趋势门槛     | `recordCount >= LIMITS.minimumTrendEntries`（3 条）才输出趋势结论，否则显示“实际记录不足 3 条”    | `shared/constants.js`、pages/review/insights                            |
| 排序（档案） | 月份档案卡片按日期倒序；月历按自然周分块、无记录日留白                                            | pages/review/month、pages/universe                                      |
| 空态         | 月历：`本月暂无记录`；档案：空卡片列表 + 空态文案；分布：`distributionEmpty` 空态；时间线：空列表 | 对应页面 WXML                                                           |
| 装饰读写     | get 只带月份；replace / reset 带 `expectedVersion` 乐观锁；云端未开放时页面只读展示未实现态       | pages/universe 装饰面板                                                 |

字段待Xiang Yu独立复核：本地校验器通过只能作为验证证据，不代替成员确认。

## 3. 统计样例（合成样本，与 `tests/review-week2.test.js` 的 Z04 用例一致）

时钟固定 2026-10-18（fixture clock），账号 a。

| 样例                       | 窗口  | 实际记录 | 分布结果                                         | 趋势显示              |
| -------------------------- | ----- | -------- | ------------------------------------------------ | --------------------- |
| 0 条                       | 30 天 | 0        | `distributionEmpty=true`，各分类 `0/0 条`（`—`） | 不足 3 条，不输出趋势 |
| 2 条（10-18 晴、09-25 雨） | 7 天  | 1        | 晴 `1/1 条 100%`，雨 0                           | 不足 3 条             |
| 2 条（同上）               | 30 天 | 2        | 雨 `1/2 条 50%`、晴 `1/2 条 50%`                 | 不足 3 条             |
| 3 条（+10-17 多云）        | 30 天 | 3        | 各类计数合计 = 3（分母 = 记录数）                | 达到门槛，输出趋势    |
| 3 条（同上）               | 90 天 | 3        | 同上，`窗口 90 天 · 实际记录 3 条`               | 达到门槛              |

跨窗口结论：7 天窗口过滤掉 09-25 的记录（实际记录 1 条），90 天窗口不放大分母；窗口切换只改变统计范围，不改变“分母 = 实际记录数”。
