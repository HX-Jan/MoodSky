## 1. 接入方式

- 云模式下月历与月份档案统一走正式 service：`reviewReader.calendar(month)` / `reviewReader.monthArchive(month)`，底层为 `review.calendar`、`review.monthArchive` 契约，全部响应先经 reader 校验（`contracts.js` + `validateResponse`）。
- 演示模式行为保持 W1 语义不变（demo-service + demo-store），云模式 harness 中 demo-service / demo-store 为禁用替身，一旦被触碰立即抛错。
- 序列令牌（`_requestSeq`）保证切月后旧月份响应被丢弃；网络失败走 `reviewErrorMessage` 统一文案并保留重试按钮。

## 2. 场景覆盖（tests/review-week2.test.js）

| 场景             | 用例                                                                        | 断言要点                                                                                                           |
| ---------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 空月（月历）     | `cloud calendar renders an empty month as blank grid and empty archive`     | 2026-09 渲染 30 个非空白格子且全部无记录；`monthSummary=本月暂无记录`；无错误提示                                  |
| 空月（月份档案） | 同上                                                                        | `recordCount=0`、`cards=[]`、`loading=false`、无错误                                                               |
| 有记录月         | `delete syncs universe, archive and detail`（初态断言）                     | 月历 `monthRecordCount=1`、档案 `recordCount=1` 且卡片就绪                                                         |
| 切月 / 过期响应  | `late cloud calendar response cannot replace a newer month selection`       | 首月响应迟到时被令牌丢弃，视图保持 2026-09                                                                         |
| 网络失败         | `cloud calendar network failure keeps the page empty and recovers on retry` | 失败时周块清空 + `连接失败，请重新读取。`；重试后恢复 1 条记录                                                     |
| 无演示数据混入   | 全部云模式用例 + harness 禁用替身                                           | demo 读数为 0；页面数据不含演示种子内容                                                                            |
| 正文边界         | 装饰用例内的请求动作断言                                                    | 云模式下页面只发出 `review.calendar / review.monthArchive / review.decorations`，正文仅由详情页 `journal.get` 读取 |

## 3. 保留的产品规则（W1 延续）

- 无记录日留白，不填充占位内容。
- 天气分类沿用五类（SUNNY/CLOUDY/RAINY/STORMY/SNOWY）映射。
- 月历卡片默认隐藏正文（`maskedBody`），展开交互与 W1 一致。
