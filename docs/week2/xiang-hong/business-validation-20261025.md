验证包由 `node scripts/package-business-validation.js` 构建，函数名仍为 **moodsky-h03-probe**。这属于新的部署/批次申请，不复用此前已消耗的 H03 单次授权。

1. 在同一环境 `mood-sky-d5gqy3spkff37566d` 临时更新既有探针函数，保留运行时、超时、内存和既有操作者指纹配置。
2. 仅执行一次固定批次 **h03_20261025_business_001**；入口仅接受该批次的 run/inspect。重复 run 会拒绝，不覆盖已有批次。
3. 仅允许四个原探针集合的新批次合成行。accounts 与 task_templates 映射至 h03_probe_accounts；journals 至 h03_probe_journals；request_receipts 至 h03_probe_receipts；task_history 与 deletion_markers 至 h03_probe_deletions。每次查询附带固定批次和标签；写入必须在事务内，覆盖前检查同批次。模板和账号、任务和记录使用不同确定 ID 与账号，避免既有唯一索引相互影响。
4. 九组检查执行当前实际业务服务：新建/原请求重放、七天气编辑、版本并发、本人隔离与档案不含正文、任务同请求并发、任务终态并发、历史分页/隔离、注入异常后的真实事务回滚、停用账号拒绝。合成正文只写本批次；不调用正式私人账号。断言失败时保留失败报告，不宣称成功。
5. 保存结果后，将探针恢复到本轮实际下载的原三文件备份，并重新下载对比。恢复失败时停止并明确报告。所有旧批次及本次合成数据保留。
