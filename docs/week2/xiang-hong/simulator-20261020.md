## 环境和证据边界

在实际微信开发者工具窗口运行原生 WXML/WXSS 页面，执行按钮点击、文本输入、页面跳转、返回和隐藏生命周期。界面通过原请求/响应校验器访问本机 loopback Node 业务服务，服务使用本周组装入口与合成事务数据库；不是静态成功响应，也不是实际 CloudBase 数据库。

仅隔离副本修改 API 传输、关闭实际云初始化、添加 SIMULATED 水印、为 localhost 放行副本的域名检查；业务源文件和用户原工作区未修改。服务器绑定 127.0.0.1，不向局域网公开。API 中的账号切换、停用和外部写入均为合成测试控制，不等于真实微信账号切换。

## 工具故障及处理

首次自动化连接超时，后续页面读取和所有用例正常执行。测试脚本在命令行传递带 `&id=` 的 URL 时被 Windows 命令解释器截断；保留中间 26 项通过结果，改用受支持的运行时 wx.navigateTo 传原 URL 后继续，最终 33 项通过。此为测试驱动参数问题，没有因此修改产品代码，也没有删除失败过程或宣称首次脚本全程无误。
