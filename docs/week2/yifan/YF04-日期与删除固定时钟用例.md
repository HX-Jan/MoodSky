# YF04 日期与删除固定时钟用例

以下为可执行的预期清单，不代表九项均已在当前微信或真机执行；成员截图还存在旧界面版本差异。约定：测试时钟固定为 2026-10-21（周三），用例中不写"当天"。

| 用例               | 输入日期               | 预期                                             |
| ------------------ | ---------------------- | ------------------------------------------------ |
| C1 新建-今天       | 2026-10-21             | 可保存                                           |
| C2 新建-窗口内     | 2026-09-22（前29天）   | 可保存（补记）                                   |
| C3 新建-窗口边界外 | 2026-09-21（前30天）   | 服务端拒绝 INVALID_INPUT，页面只读提示           |
| C4 编辑-旧记录     | 2026-08-15 已有记录    | 携当前 expectedVersion 可编辑                    |
| C5 冲突            | 同一记录两版本并发保存 | 后到者 CONFLICT，保留草稿与原请求                |
| C6 删除            | 任意已有记录           | 二次确认后删除成功，版本校验通过；删除后回顾刷新 |
| C7 标签上限        | 任意日期               | 第 6 个标签被拒绝                                |
| C8 正文上限        | 1001 码点              | 保存禁用（客户端前置）+ 服务端复核               |
| C9 emoji           | 😀 字符                | 按码点计 1，计数正确                             |
