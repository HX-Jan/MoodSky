## 5. 尚需真实执行的复核

1. 固定验收 commit、微信基础库、机型/系统/微信版本；记录真实入口和截图时间。
2. 用合成文本执行必选/可空、保存失败、结果未知、切日期、重新读取、取消与放弃；覆盖返回键、手势、隐藏/返回，实际 API 不支持时记录降级效果。
3. 375/390px、小屏、200%字体/系统放大、键盘弹出、长中文/emoji、读屏与焦点。只记录已执行环境，不能把浏览器通过改写成微信真机通过。
4. Me 偏好影响范围与演示导出、模拟注销分别复核；正式身份、真实数据和正式云健康由其负责人按授权执行，设计包不创建真实写入。
5. 四位负责人实际回传后按问题编号更新“已接收/待修正/已复测”，保留修前修后证据。真实需求访谈按研究汇总的实际样本计数，不计为后期 12 人可用性指标。
