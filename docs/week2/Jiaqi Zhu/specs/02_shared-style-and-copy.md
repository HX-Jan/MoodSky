## 5. 触控目标与可访问性待复核

原型的日期/月份导航采用 44×44 CSS px，主操作最小 48px 高。紧凑月历格在 390px 视口约 42px 宽、320px 视口约 32px 宽，没有声称全控件达到 44×44；每条有记录日期另提供最小 44px 高、整行可点的等价文字列表。WCAG 2.2 AA 的目标尺寸为 24×24 CSS px（有间距等例外），44×44 是增强目标，不能混称为 AA 要求；等价入口仍需在实际视口与读屏中复核。依据：[W3C 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[W3C 2.5.5](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)。
