# 研究证据、引语与缺失样本规则

适用：W2 JQ03/JQ04；2026-10-23。两位访谈员共同复核尚待实际执行，本页是建议记录协议。

## 五类内容分开

| 标识       | 可写内容                       | 使用条件                                                                      |
| ---------- | ------------------------------ | ----------------------------------------------------------------------------- |
| Q 原话     | 参与者的实际措辞，可加引号     | 当场准确记下，注明 P 编号、题目/证据 ID、澄清前后；不能把事后回忆写成逐字原话 |
| P 转述     | 参与者意思的概括，不加引号     | 明确标“转述”；若结束后补记，注明补记与无法确认之处                            |
| S 来源摘要 | 对已提交文件的回答表再摘要     | 标清源文件、P 编号和主题；原表未说明 Q/P 时，只能保守写来源摘要               |
| O 观察     | 实际看到的动作、解释、页面状态 | 真实观看才记；自报“会点这里”不是已观察到任务完成；需求访谈不计成功率          |
| I 设计解释 | 设计者对风险、需求和修订的判断 | 与 Q/P/S/O 分栏，提供依据和未确定点；不能伪装成受访者说法                     |

目前 P07—P12 源表没有区分逐字原话/转述，因此 W2 只使用 S；源文末尾“分析与待验证建议”属于原记录者解释，不进入参与者提及频数。新增 P01—P06 按 Q/P/O/I 直接分栏。

## 接收、去重和计数

1. 有源文件和编号只能证明材料存在。另记：实际执行报告、两项同意、使用范围、去身份化、撤回与跨人去重。
2. UNKNOWN 是未取得证据；NO 是实际拒绝。两者不可替换。缺记录也不能反推“未访谈”。
3. 同一人在同一主题提到多次只计一次；同一人的多份记录合并来源，不增样本；同一编号出现两个实际参与者则停用并重新分配，不静默覆盖。
4. 编码先给定义，再列 P 编号和原主题。明确记录提及数与正式独立样本数的区别。当前初步 n/6 是材料提及数，正式独立人数待同意与去重核对。
5. 新材料正式纳入后，以该题实际有效回答人数为分母；“未问”“跳过”“不确定”“中断”“撤回”分别登记，不能算作“无问题”。不同原型版本分组，不混算理解差异。
6. 汇总同时找反例和分歧；不要把问卷统一题目带来的相似回答写成“全部自发提出”。不从少数定性材料外推全校比例或因果结论。
7. 优先级按风险、路径阻塞与修复成本评估。隐私/数据丢失顾虑即便只出现一份也可优先，但要标为设计判断。

## 同意、撤回与最小记录

默认不录音。参与者自愿、可跳题、可随时结束；两项同意分别取得。若当前匿名笔记使用许可无法确认，不把已有材料记为正式可用样本；由实际执行者核对允许范围，不伪造追认。撤回后移除相关研究内容、引用与汇总贡献，仅留最小“编号已撤回”状态和修订日期。

共享仓库不收集真实日记、诊断/病史、姓名、学号、微信号、电话号码、宿舍、精确行踪、聊天截图或编号—身份映射。背景只记与研究有关的记录习惯/查找方法。出现敏感内容不抄写，转回工具问题。既有来源文档保留其历史，本包不扩大复制非必要细节。

参与者凭 P 编号通过原邀请渠道请求撤回；负责人收到后检查记录、摘录、计数和原型决策依据是否需要更新。保存范围与期限由项目负责人和参与者确认，本包没有擅自填已获得长期公开许可。
