## 1. 开始前必须确认

真机测试不是直接扫码就能做，先确认以下三项：

1. **体验版已上传**：由 @HX-Jan 在微信开发者工具上传代码，并在微信公众平台“版本管理”中把开发版本设为体验版。
2. **你的微信号已加入体验成员**：由 @HX-Jan 在公众平台“成员管理 → 体验成员”添加你的微信号。
3. **确认本次包的模式**：
   - 当前仓库个人配置为 `cloudEnabled:false`、`journalDemo:true`，上传后是**本地演示模式**，可验证页面、保存、回顾刷新和缓存。
   - 生产 `journal`/`review` 仍返回 `NOT_IMPLEMENTED`，因此**即使开启云，也不能验收真实云端保存**。
   - 真机本轮只能验证：页面布局、天气选择、演示保存/编辑/删除、回顾刷新、账号门禁展示、Campus 定位拒绝、Me 偏好与失败提示。
   - 不要用真机输入真实日记、真实姓名、手机号或其他隐私信息。

## 2. 安装体验版

1. 让 @HX-Jan 在微信公众平台打开“版本管理 → 体验版”，生成体验版二维码。
2. 用华为 Pura 70 的微信扫描该二维码。
3. 首次打开若提示“体验版”，确认进入；若提示无权限，说明微信号未加入体验成员，回到第 1 步。
4. 打开后点右上角“…”→“关于”，确认小程序名称和版本；记录版本号与打开时间。
5. 若之前打开过旧版本：右上角“…”→“设置”→“清除缓存”，或长按小程序卡片删除后重新扫码。

## 3. 测试前准备

- 连接稳定的 Wi-Fi 或 4G/5G，记录网络类型。
- 清理小程序缓存，确保从空状态开始。
- 准备截图/录屏；截图前检查不要包含真实身份、聊天或其他私人内容。
- 记录：设备型号、HarmonyOS 版本、微信版本、体验版版本号、测试时间、网络。

## 4. 建议执行步骤

### A. Today 保存与重新进入

1. 打开 Today，确认页面显示五类或当前版本支持的天气选项。
2. 只选一种天气，不填正文，点保存。
3. 等待明确成功提示；记录保存后的天气和版本。
4. 完全退出小程序（上滑关闭），重新打开 Today。
5. 预期：同一天仍能读到刚才保存的天气；演示模式数据不丢失。

### B. 编辑与回顾刷新

1. 打开当天记录，修改天气或正文并保存。
2. 不重启小程序，直接进入 Universe。
3. 预期：月历当天显示修改后的天气；不需要重启才能看到最新数据。
4. 打开当天详情，确认正文只在本人详情显示，月历卡片不直接显示正文。

### C. 删除与取消

1. 在记录页点删除，先点“取消”。
2. 预期：记录仍在，没有发生删除。
3. 再次删除并确认。
4. 预期：记录消失；Universe 月历、档案和详情同步刷新。
5. 对同一天再次删除，预期为幂等结果，不误删其他日期。

### D. 账号门禁与任务入口

1. 进入 Me，查看账号状态和模式（演示/云）。
2. 进入任务入口，确认能看到建议列表；游客或未登录状态不能写入任务状态。
3. 切换合成账号（若当前包提供两个演示账号），确认 A/B 数据不串号。
4. 预期：旧账号的偏好、导出和任务历史不出现在新账号。

### E. Campus 定位拒绝

1. 进入 Campus，先浏览列表，确认不主动弹定位。
2. 手动点“使用定位”或页面上的定位入口。
3. 在系统弹窗选择“拒绝”。
4. 预期：页面提示定位未授权/不可用，但仍可继续浏览地点列表。
5. 再点一次定位并选择“允许”，记录是否取得位置；拒绝后不应阻断列表。

### F. Me 偏好与失败提示

1. 进入 Me，修改一个显示偏好并保存。
2. 退出后重新进入，确认偏好仍在。
3. 在保存或导出流程中制造失败（如断网/关闭网络），确认页面保留输入并显示失败，不显示虚假成功。
4. 若页面显示 `NOT_IMPLEMENTED` 或“未实现”，记录为真实缺口，不要当成通过。

### G. 弱网/断网

1. 打开飞行模式或关闭 Wi-Fi/移动网络。
2. 在 Today 保存一条合成记录。
3. 预期：显示网络失败，输入保留；不要出现“保存成功”。
4. 恢复网络后按页面提示重试；若页面支持，确认复用原请求而不是新写一条。
