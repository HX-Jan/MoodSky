## 已完成实现

- 列表项通过 `getPlace(placeId)` 打开详情；加载、失败、重试和关闭状态分开处理。
- 迟到的详情响应不能覆盖用户后来打开的地点；响应缺少预期地点 ID 时显示格式错误。
- 详情展示区域说明、开放信息、记录日期、来源和资料状态。
- 定位仅在用户点击后请求。拒绝或接口不可用时，页面状态提示仍可继续浏览；定位结果不保存或上传。
- 地图只有在已有正式核验状态、有效日期、明确坐标系及有效坐标的情况下才可打开。QH01 五条成员记录的坐标未导入小程序数据，因此全部保持不可导航。
- 地图能力失败保留列表返回路径；地图字段不完整时不会调用 `openLocation`。
