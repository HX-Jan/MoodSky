# W3 手机端最简清单

> 目标：在手机上完成体验版验证与授权；上传新包、部署云函数仍需 PC/管理员操作。

| #   | 手机上做什么                                                    | 完成标志              |
| --- | --------------------------------------------------------------- | --------------------- |
| 1   | 微信公众平台 → 版本管理 → 将最新开发版设为体验版                | 看到体验版版本号      |
| 2   | 成员管理 → 添加你的微信号为体验成员                             | 你的微信能扫码打开    |
| 3   | 扫码打开体验版，记录版本/微信/机型/系统                         | “关于”页截图          |
| 4   | Today：选一种天气保存 → 切页返回 → 重进                         | 记录是否保留或提示    |
| 5   | Universe：编辑/删除/重建 → 看月历、档案、详情                   | 截图刷新结果          |
| 6   | Campus：浏览 → 点定位 → 拒绝 → 再允许                           | 记录提示，列表仍可用  |
| 7   | Me：改偏好 → 重进；看未接入/失败提示                            | 截图                  |
| 8   | 任务/后台：打开入口，记录只读、未实现或失败                     | 截图                  |
| 9   | 把“版本 + 每步通过/失败/阻塞 + 截图”发回本对话                  | 我更新 YL04/YL03/YL02 |
| 10  | 回复：批准部署 `a2a6719 / mood-sky-d5gqy3spkff37566d / moodsky` | 我准备部署与回滚清单  |
| 11  | 回复：批准真实云 A/B 批次                                       | 我准备固定批次方案    |

说明：第 1 步的“上传开发版”需要 PC 上的微信开发者工具；手机端只能把已上传版本设为体验版并添加成员。第 10、11 步是授权，实际部署/云写入需有权限的人在 PC 或云控制台执行。
