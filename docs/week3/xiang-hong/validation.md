# 2026-10-26 W3首轮本地验证

源码基线`4a35bc7ec6935adcd5b662a0b77e7cb734d8b699`，Node.js `24.21.0`。本报告对应本PR源码及其测试；不是新云实验、手机包或独立成员验收。

## 缺陷与修复

先在原页面实现上增加12条会话切换回归，20项页面测试中原8项通过、12项新增检查失败，复现旧私人名称/正文被迟到响应重新填回。修复后监听已建立的服务端账号绑定变化，清空月历、月份档案、详情及统计的旧视图，同时递增页面读取令牌；reader自身也拒绝已失效会话的结果。

首次登录在读取期间建立绑定仍允许正常完成；A→B→A、清空后重新认证也会废弃旧读，不仅比较最后scope字符串。没有自动生成写请求、切换重试ID或触发云部署。每次读取的监听在成功/失败后释放，页面监听在卸载后释放。
