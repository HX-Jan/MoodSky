# 微信开发者工具页面检查 2026-10-30

环境：Windows，微信开发者工具 Stable 2.01.2510290，模拟器 iPhone 12/13 外观；不是手机实测。基础库界面显示3.17.6。

实际操作及观察：

- 校园页可进入，首次未使用定位。
- 云配置关闭时显示地点列表读取失败、云服务尚未配置，没有自动替换为本地数据。
- 手动选择成员提交资料后显示5条、本地预览、待复核、未写入云端。
- 初始显示福友阁、大梦书屋；第一次加载下一页追加望舒湖、阳光园；第二次追加光彩创咖，随后显示列表末尾。
- 点击福友阁后，详情位于列表下方，滚动可见；显示工作日15:00–21:00、非工作日09:00–21:00、记录日期2026-10-21。
- 详情导航和收藏按钮禁用，提示坐标系未确认、预览不读写真实收藏；纠错表单标明不会提交。
- 点击支持资源接入状态，显示当前没有已核验且仍有效的支持资源。
- 展开固定天气，显示固定虚构示意，并说明不读取私人天气、不采集真实贡献。

已修复并在模拟器验证：点击地点后自动滚动到详情，无需手动寻找。使用 scroll-into-view，重新请求详情时重置目标。
控制台可见共享status-feedback组件WXSS选择器警告（index.wxss:33:1）；未对共享组件进行修改。

未在本轮实际覆盖：筛选选项组合、定位拒绝/撤回、地图失败注入、真实账号收藏纠错、全部地点逐条详情。已有Node测试不替代这些UI证据。
