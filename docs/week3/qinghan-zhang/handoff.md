## 人工补测步骤

记录源码版本、微信版本、设备、日期、预期、实际及截图路径；不得提前填通过。

1. 首次打开校园页，不授权定位仍可浏览已有资料。
2. 点击定位并拒绝；离开页面，在系统中撤回权限，再进入页面并重新请求，确认不沿用成功提示。
3. 打开无坐标地点，确认文字详情与返回路径可用，不能启动导航。
4. 在明确的测试数据环境模拟地图失败，确认列表仍可操作。
5. 后端就绪后验证列表筛选、分页重叠、空结果、失效地点和网络失败重试。
6. 后端就绪后以A/B分别读写收藏；未登录、停用、恢复状态分别记录，不能使用本地模拟替代账号隔离证明。
7. 纠错输入空白、1、200、201个Unicode码点，重复点击和失败重试；提交响应不能表示审核完成。
8. 支持资源为空/过期/读取失败分别检查；固定校园天气保持模拟标识，不读取私人天气。

## 学习与交接

request generation 用于忽略迟到响应；requestId 用于原请求重试；Array.from(text).length 计算Unicode码点。
排错时先检查页面状态与请求入参，再检查响应和错误码，最后核对服务端是否实现。
成员实际耗时、难度点和独立复核意见待本人/复核人填写。功能测试不能代替独立签认。
