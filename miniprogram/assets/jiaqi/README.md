# Jia7Zhu W1 原创界面素材

原始素材位于 docs/design/w1/assets/weather/ 和 docs/design/w1/design/design.json，来自 PR #12 / a01e5b64d5469251738fe80da084f88c3e7c7204。团队原稿允许在本项目中使用、修改和导出。

天气 SVG 按原样导出为 128×128 PNG；导航及界面图标从设计数据中的同名 SVG 导出为 64×64 PNG。普通/选中图标只使用原稿 secondary / brand 两种色值；没有下载外部图标或字体。逐文件来源和 SHA-256 见 manifest.json。

HEAVY_RAIN、TYPHOON、CUSTOM 只用于未开放的设计入口，不新增可保存的天气编码。
